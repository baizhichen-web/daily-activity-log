# 设计参考 R-37：Studio Loop（巴西创意工作室）

> 采集：2026-08-31（凌晨会话）· **白纸点名「我喜欢的一种设计类型」**——重要的口味信号
> 采集方式：chrome-devtools 实拍首屏/第二屏 + 无头 Edge 整页 + DOM 文本（页面动画重，MCP 截图会卡，走 $TEMP 中转）

## 这是什么

巴西圣保罗创意工作室 ohaloop 的官网（客户：Macy's / Paramount / Universal Music / TikTok Ad Awards / Food52…）。自我定位一句话三段：**STORIES. SYSTEMS. INTERNET.**，口号「CREATIVITY AS A SERVICE」「[ FROM BRASIL TO EVERYWHERE ]」。

## 视觉类型拆解（白纸喜欢的点大概率在这些）

1. **俯视桌面拟物开场**：首屏=一张深巧克力棕的"桌面"，橙色丝绒扶手椅、玻璃台灯、郁金香边几、斜放的书封、钥匙扣纪念品**俯视散落**，像从正上方看一张真实工作台——不是网格排版，是"物件落在桌上"
2. **品牌词具象化**：一只**橙色有机波浪形**从首屏贯穿到内页——它就是品牌名 loop 的形状；"oh, I just had a loop" 钥匙扣、loop 手写 logo，抽象概念（循环/灵感）全变成可触摸的小物件
3. **贴纸手写体 + 衬线混排**：物体上贴着语音气泡式贴纸字（"Deep ~ culture,"）、不同字重混搭；服务列表用**无衬线大字 + 橙色衬线斜体强调词带下划线**（"Video & Social *Content*"）
4. **编辑部标签系统**：`(01)` 括号编号、`[ FROM BRASIL TO EVERYWHERE ]` 方括号小字全大写标签——纯排版的仪式感，零资产成本
5. **暖色胆量**：深棕打底，橙/奶油纸色/淡紫黄撞色——整个站像一间暖色调的工作室，与主流白底极简完全反着来
6. **CTA 有性格**："Your next project starts **looping** here"（把品牌动词塞进 CTA）；Newsletter 叫 "JOIN THE LOOP"

## 取 / 不取（对我们）

- **取**：① **编辑部混排系统**（衬线斜体强调词 + 括号编号 + 方括号标签）——纯 CSS 就能做，简历页/项目页直接可用（→G-30）；② **品牌词/座右铭具象成一个贯穿形**的思路——"如切如磋如琢如磨"可以想想有没有自己的"形状"（磨痕/刻线），这是设计层大题，白纸拍板；③ 暖色调的胆量样本——白纸喜欢此类型 = Design.md 色调讨论的重要一票（现草稿方向是暖纸白系，同族）；④ "物件=人格"的思路：桌面上的每件东西都在替主人说话
- **不取**：**整套 3D 拟物散物路线**——重资产（摄影/3D 建模每件物件），且是营销站的形态，与翻页书 MVP 结构错位；采样时它的意义是**类型口味**，不是待抄结构
- **候选基因**：G-29 桌面拟物散落（⏸，白纸明示喜欢但重资产，V2+）；G-30 编辑部混排（⏸，低成本高兼容，可与 MVP 直接合）
