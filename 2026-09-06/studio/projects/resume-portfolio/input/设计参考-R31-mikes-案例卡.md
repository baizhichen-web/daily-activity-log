# 设计参考 R-31：Mike Barton / mikes.cv（航空主题个人站）

> 采集：2026-08-30 · 白纸点名三巧思（舷窗昼夜开关 / 飞机连简历时间线 / 机票刷卡开场）
> 本轮静态实测（构建架构+源码注释）+ 白纸目视与 X 书签截图（NORTHERN AIR 机票卡）；动效细节待浏览器复核

## 这是什么

Software Designer Mike Barton 的**航空旅行主题**作品集——整个站是一场"飞行"：登机=进站，舷窗=昼夜，简历=航线。X 上 830 赞的出圈设计。

## 三巧思拆解（白纸点名）

1. **舷窗开关 = 昼夜模式**：模式切换不做太阳/月亮按钮，而是一只**飞机舷窗的遮光板**——拉下遮光板进黑夜模式。实现印证（源码注释）：`theme.js` 在**首帧绘制前**从存储读偏好设 `data-theme`，闪屏在内的所有绘制都读这个底色——切换零闪烁，这是主题切换的工程正解
2. **飞机效果连简历时间线**：简历经历不是列表，是一段**航线**——飞机沿线飞过各站（=各段经历），时间线叙事化
3. **机票刷卡开场**：进站动画是一张**登机牌（NORTHERN AIR / MIKE BARTON / FLIGHT TD18）刷过读卡机**——"请登机"即"请进站"，主题设定从第一帧开始

## 架构实测

Vite SPA（2.3KB 壳 + 单 bundle）、`noindex`、theme.js 预置底色（见上）。机票卡视觉：米白卡面 + 蓝字等宽排版 + 航空公司小徽标 + 撕裂线，登机牌的所有格式细节都在。

## 取 / 不取（对我们）

- **取**：① **theme.js 预置底色工程**（我们暗面 Hero + 未来明暗切换直接可用的正解，与白纸"禁手写日期"同级的技术纪律）；② **"入职手续"式开场隐喻**（我们对应物：座右铭逐字渐显已是"开场"，登机牌思路进 backlog 作重做候选）；③ **时间线叙事化**（简历时间线 + G-16 热区图/航线的结合想象，V2 候选）；④ 登机牌的信息排版（撕裂线/等宽字/徽章）可用于项目卡
- **不取**：全套航空主题（身份是它的，不是我们的——我们的主题语言是"纸/证据/打磨"）
- **候选基因**：G-25 舷窗遮光板昼夜切换（⏸ 候选）；G-26 刷卡式开场动画（⏸ 候选）；航线时间线叙事记入卡内不立基因
