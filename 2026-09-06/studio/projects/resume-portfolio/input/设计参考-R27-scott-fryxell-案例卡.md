# 设计参考 R-27：Scott Fryxell（主页 + 简历页）

> 采集：2026-08-30 · 白纸点名参考（"比较简单，但有一点小动效，特别是打开博文项目的时候"）
> chrome-devtools 实测（DOM/样式/交互探测 + 视口截图）· 两页：`/` 博客主页、`/resume/` 网页简历

## 这是什么

「Humanist Software Developer」的极简个人站，GitHub Pages 托管。两页共同点：**几乎零 JavaScript**（主页 0 个脚本、简历页 1 个），全部效果靠现代 HTML/CSS 原生能力实现。暖白底 rgb(246,245,244) + 深字 rgb(33,31,28)，Lato 单字体——与我们 #FAFAF7 暖纸白同族。

## 主页：海报墙 + 原生展开

- **每篇博文 = 一张全幅水彩风 SVG 海报**（29 图 27 SVG），整页像海报墙纵向叠放（12763px）；标题+日期叠印海报左下，右下角一个 **+** 号。
- **展开动效（白纸点名的那个）**：点 + → 原生 `<details>` 打开 → 全幅海报**收缩为右侧窄列图**，标题移到左侧大字，+ 旋转为 ×，正文在下方居中列浮现——**全部 CSS，零 JS**。
- 26 个 `<details>`（每博文一个）；summary 网格纸配色、summary marker 隐藏等细节干净。
- 结构：极简顶栏（名字+身份 | Resume / Thoughts 两链接）→ 海报流。65 个链接全为站内博文。

## 简历页：网页即简历

- 结构化网页简历：定位段（"Everything I make starts from the same question: who is this for and how does it respect them?"）→ Experience 18 段经历（H3 公司+职位一条龙，带叙述）→ 联系方式进顶栏。
- **机读简历**：全页 schema.org microdata（itemscope/itemprop/headline/datePublished）——搜索引擎与机器可直接解析其履历结构。
- **没有 PDF**：页面本身就是简历（可打印性应靠 @media print CSS，未见打印按钮）；与我们「双语 PDF 链接占位」方案可对照。

## 取 / 不取（对 MVP 翻页书）

- **取**：① **展开动效的语法**（+ 旋转 ×、大图收缩、正文浮现）——可用于项目页内「展开看细节」或作品条目，与翻页书不冲突（翻页=页面级导航，details=页内展开，两层正交）；② 网页即简历 + microdata 机读（我们的简历页可加 schema.org 标注，SEO 加分项，成本极低）；③ 海报化封面思路（每项目一张主视觉图，与 Behance 式大图流同构）；④ 暖白底色系再次佐证；⑤ 零 JS 纪律（动效预算可以极低但极精）。
- **不取**：纯文字无视觉记忆点的顶栏（我们有座右铭+幽灵字体系）；18 段经历的密度（我们简化版只放重要信息）。
- **技术对照**：它是「HTML 原生能力派」的极致示范——原生 details、原生语义、原生机读；我们是 React 派，但 **details 展开这种交互完全可以用原生元素嵌进 React**（React 渲染原生 details 即可），不必自己写展开动画。
