# 设计基因库（Design Gene Bank）

> 目的：把白纸一点点发来的网页设计参考，从「收藏」转化为「可迁移的设计基因」——本文件是转化层的唯一容器，PRD §7 与 V2 视觉策展的直接上游。
> 流水线：**接收**（原始内容落位+编号）→ **吸收**（案例卡+打标+截图）→ **转化**（基因入库+标本册加卡）。
> 规则：一条基因 = 「描述 + 来源参考编号 + 适用位置」。宁缺毋滥，每条都要能回答「上站后它帮访客解决了什么」。
> 编号：R-01 起；Eagle 同步打编号标签，检索即得全套证据。

## 总基调（2026-08-25 白纸定调）

> **「我希望我的页面是这样的即可，不用像 Lusion 那样有很复杂的组件，但是像这样干净、有调性就行。」**
> 锚点 = **HY-LAB（R-03）**。翻译成设计语言：干净的中性底色 + 巨字排版 + 全站唯一的高饱和色时刻 + 少量标本卡点缀；**拒绝**复杂组件、重 3D、加载动画大戏。Lusion 降级为「微交互细节供应商」（悬停反馈等），不再是整体气质来源。

## 基因登记

### G-01 悬停即时反色反馈
- **描述**：按钮/可点元素在悬停瞬间完成状态反转，无过渡延迟，反馈感极强
- **来源**：R-01 Lusion Of The Oak（LAUNCH PROJECT 按钮悬停帧）
- **适用位置**：全站按钮、项目卡片、外链
- **状态**：✅ 定调可用（简单微交互，符合「不复杂」原则）

### G-02 滚动渐进叙事
- **描述**：滚动即推进剧情，层间过渡本身是叙事
- **来源**：R-01 Lusion Of The Oak（滚动状态帧 ×2）
- **适用位置**：项目详情页（完整形态）
- **状态**：⏩ 降级至 V2——白纸明确不要复杂组件；V1 只取「分节渐入」的节奏感

### G-03 对偶文案立场表达
- **描述**：双栏对偶词组（HUMAN/SOCIETY/CULTURE ↔ NONHUMAN/TECHNOLOGY/NATURE），一屏讲清立场
- **来源**：R-03 HY-LAB hero（全页截图 01）
- **适用位置**：About 定位宣言、Hero 副标题
- **状态**：✅ 定调（R-03 为全站锚点）

### G-05 巨字排版压阵
- **描述**：超大号字重排版作第一视觉层（hero 全大写、footer「DESIGN & FUTURES」、栏目页居中巨字），文字即图形
- **来源**：R-03 HY-LAB（截图 01/09/11）
- **适用位置**：Hero、板块标题、页脚品牌宣言
- **状态**：✅ 定调（与设计声明「排版即设计」同向）

### G-08 色彩克制两级制（2026-08-31 升级改版）
- **描述**：色彩克制分两级——**全局界面纯中性**（黑白灰，强调=墨黑，Design.md v2 A2）；**每个项目在其页面内有一个主色时刻**（--accent-project 注入位，白纸 Figma 定稿逐项目赋值）；跨项目不得同时抢色
- **来源**：R-03 HY-LAB（原"荧光色块整屏时刻"），2026-08-31 Design 过审升格为两级制
- **适用位置**：全局=状态/反馈/悬停用墨（或项目页内项目主色）；原"一处高饱和色整屏"（页脚/菜单荧光色块）随黑白强调体系**废止**
- **状态**：✅ 定调（Design.md v2 同源）

### G-09 箭头+胶囊 section 头
- **描述**：区块头 = 左「→ 标题」+ 右胶囊按钮（All Projects）+ 发丝分隔线；导航语义清晰且零装饰重量
- **来源**：R-03 HY-LAB（截图 03/04/05）
- **适用位置**：精选项目/写作/简历各区块头
- **状态**：✅ 定调

### G-10 数据标本卡拼贴
- **描述**：把数据图表做成「标本卡」——编号（#000512）+ 日期 + 雷达图/图表 + 手绘感插画，浮游叠在排版上；科研数据被当成植物标本收藏
- **来源**：R-03 HY-LAB（截图 02 XianGong Garden 标本卡）
- **适用位置**：**白纸的招牌章**——看板数字、会话轨迹、bench 对比、SCI 数据都可以做成标本卡；与本项目「参考标本册」做法天然同频
- **状态**：✅ 定调（潜力最大的一条：把「AI 工作空间」章从截图墙升级为数据标本墙）

### G-11 小写极简题注
- **描述**：项目名以小写单词置于图下（xiangong / birdseed），无边框无装饰，留白即框
- **来源**：R-03 HY-LAB（截图 04）
- **适用位置**：精选项目列表、写作列表
- **状态**：✅ 定调

### G-12 全屏色块菜单
- **描述**：菜单 = 整屏高饱和色块 + 大字导航项 + 右上角联系方式 + 右上 X；导航本身成为调性载体
- **来源**：R-03 HY-LAB（截图 10）
- **适用位置**：全站导航（桌面端汉堡/角标触发）
- **状态**：✅ 定调

### G-13 排比宣言句库
- **描述**：品牌人格靠「主语 + 动作短语」句式重复建立（Trestle Inc. believes in better defaults / talks with the taxi driver / … ×14），一句一屏滚动揭示，巨衬线字行级渐入
- **来源**：R-06 Trestle Inc.（trestle.inc）
- **适用位置**：About 宣言页或 Hero——「白纸上 + 短语」句库（如：believes in 表达式学习 / ships things that matter / remembers every project）
- **状态**：✅ 强候选（内容成本极低、调性极高，完美符合「干净不复杂」）

### G-14 滚动逐句揭示
- **描述**：滚动推进时文字逐行/逐句渐入，红点进度指示节数；比重滚动叙事简单一个数量级
- **来源**：R-06 Trestle Inc.
- **适用位置**：Hero、宣言页；V1 可实现（纯 CSS/少量 JS）
- **状态**：✅ 强候选（G-02 的「合规版」——有翻页感，无复杂组件）

### G-15 访客足迹时间线
- **描述**：每次访问生成一条「Recording Nº 编号 + 城市」印记，按时间线陈列——访客行为成为站点内容与收藏品
- **来源**：R-06 Trestle Inc.（Nº 1361 Shanghai ← 1360 London ← 1359 Chicago…）
- **适用位置**：个人网站彩蛋层（V2；需记录访客 IP 归属地，注意隐私边界）
- **状态**：⏸ V2 候选

### G-16 AI 使用热区图（白纸点名构想）
- **描述**：GitHub contributions 式的热区日历，但数据源换成**白纸自己的 AI 使用记录**——今年 1 月至今每日会话/绘制轮次，「满满一张图」；可叠加**工具迁移时间线**标注（Trae → Claude Code → Codex → Code → DeepSeek Harness）
- **来源**：白纸构想（2026-08-25 夜间消息）+ 5 站先例（R-09 fardeen / R-16 paaarth / R-17 khe.money / R-21 bikash 的 GitHub 热区图）
- **适用位置**：招牌章「AI 工作空间」的核心件——活跃度即门面，且数据源独有无人撞款
- **状态**：✅ 定调（白纸亲自提出）；数据管道待设计（会话记录在 DSH/Codex 本地，需聚合脚本）
- **关联**：G-10 数据标本卡的日历形态；R-09 案例卡有完整构想记录

### G-17 状态标注体系
- **描述**：全站统一的状态语言——经历/项目打 latest · archived · ongoing · completed 斜体标签或徽章；自我显示为在线服务（「● agent_host: active」状态灯）
- **来源**：R-15 vivekupasni（latest/archived）、R-23 dhirajarya（Ongoing/Completed 徽章）、R-18 mshahnawaz（agent_host: active 状态灯）
- **适用位置**：精选项目、经历列表、页眉状态行
- **状态**：✅ 强候选（「生长型简历」的界面语言）

### G-18 实时活人感件
- **描述**：站点里放「后面有活人」的实时证据——页脚实时时钟（R-25）、Spotify last played（R-24）、访客录制编号（R-06）、天数计数器「与 AI 协作第 N 天」（R-08 momcilo 变体）
- **来源**：R-24 / R-25 / R-06 / R-08
- **适用位置**：页脚 + About；选 1-2 件即可，克制
- **状态**：⏸ V1 末/V2 候选（时钟与天数计数成本最低）

### G-19 受众分流入口
- **描述**：落地页即两扇门——「快读（给 recruiter）」vs「深读（故事）」，界面明示受众分流
- **来源**：R-12 harshdayal（Brief Read / My Story 双门 + Enter）
- **适用位置**：V1 可先做「minimal 快读页」链接（低成本），双门全屏入口 V2 再议
- **状态**：⏸ 候选（直接呼应 PRD §2 受众策略，评审时议）

### G-20 信号点阵场招牌时刻
- **描述**：Hero 背景正弦波干涉点阵——墨色低透明信号点随场值亮灭，稀疏确定性高光染苔绿；底部渐隐 mask，离屏/隐藏自动停帧，reduced-motion 只画静态一帧
- **来源**：R-26 ThreeUI「Signal Particles」（MIT，github.com/MengTo/threeui）——白纸 2026-08-25 拍板「试着把这个加进去」
- **适用位置**：Hero 背景（巨字后面），全站唯一 canvas 动效时刻
- **状态**：✅ 定调（已实现：web/src/components/SignalField.tsx，纯 Canvas 2D 移植 + 苔绿单强调改造，+0.76KB gzip）
- **红线**：仅此一处动效背景；不扩散到其他区块；不升级为 WebGL/Three.js

### G-21 展开看细节（原生 details 动效语法）
- **描述**：内容条目收合为一张封面态——角标 **+**；点开时 + **旋转为 ×**，封面大图**收缩让位**（如移至侧列/变窄），标题位移，正文在余出空间浮现；再点收合还原。原生 `<details>/<summary>` 实现或 React 内嵌原生元素，动效走 CSS
- **来源**：R-27 Scott Fryxell（scott-fryxell.github.io，零 JS 海报墙；白纸 2026-08-30 点名动效并拍板平移）——「我希望那个展开动效（+ 旋转、大图收缩）可以平移到我们项目页的『展开看细节』」
- **适用位置**：MVP 项目页内「展开看细节」；作品/写作条目可复用
- **状态**：✅ 定调（2026-08-30，白纸裁决）
- **红线**：与翻页书正交——翻页=页面级导航，展开=页内动作，不混用；动效预算内（150-600ms）；不引入 JS 动画库

### G-22 博物馆图录排版范式
- **描述**：长文/案例正文的展陈排版——Fig N. 编号图注（灰色斜体）+ 标题嵌正文段（灰标题词组后接黑正文）+ 展品图放浅灰面板 + 超大留白节奏
- **来源**：R-28 History of Software Design（Rauno，白纸 2026-08-30 点名"博文的排版范式也可以参考"）
- **适用位置**：项目页「展开看细节」后的正文排版、简历页段落、将来博客（如启用）
- **状态**：⏸ 候选（方向已认可，上站位置待白纸定调）

### G-23 左缘刻度尺导航
- **描述**：页面左缘竖直刻度尺——短刻度=小节、长刻度=章节，当前位置刻度加深+箭头标记，细线横向贯穿页面，点刻度跳转；导航/进度/位置三合一
- **来源**：R-29 Devouring Details（Rauno，白纸 2026-08-30 点名"左侧目录栏很有意思"）
- **适用位置**：与已拍「顶部中央页码指示器」（Trestle 式）为两种导航形态：顶部管"第几页/是什么"，左缘尺管"书翻到哪"；MVP 先顶部，本基因 V2 备选或并存
- **状态**：⏸ 候选（与顶部指示器的关系待白纸裁决）

### G-24 书架拟物清单

### G-25 舷窗遮光板昼夜切换

### G-31 一段话作品集（散文式界面）
