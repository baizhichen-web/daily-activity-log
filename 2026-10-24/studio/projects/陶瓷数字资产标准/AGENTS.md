## 核心结论（2026-10-20 立项时点）

1. 这是**行业标准编制**项目，不是软件开发：产出是字段规范、比较矩阵、样本池、问题清单与草案框架；"代码"只在需要批量校验/统计时出现。
2. 标准定位是**工业设计 + 产业转化**，不是文旅遗产保护。任何调研素材先按这条口径筛：它能不能被设计师/企业用来做产品与交易，而不是只用于展陈与保护。
3. 白纸的可迁移能力在**数据建设**方向最明显：LoRA 训练前的清洗/标注/质检 + 钧瓷 30×8×5 数据流（从原始记录到统计结论）→ 可转成"六字段填表规范 + 质量分级 + 可追溯复核"。但**分工未预设**（2026-10-20 白纸决定），不据此自我指派；会议后按团队安排定。
4. 数据六字段是骨架，但说明会未给具体 ISO 标准号——"ISO 口径"的出处是必须向杨老师确认的技术问题，不能自行编标准号。

## 项目特有规则

1. **保密优先**：标准未发布，材料不外传、不上传、不公开引用；对外只发白纸审过的内容。工作区 git 仓库为 private，仍按"最小必要"入库。
2. **证据分级**：每条结论附来源 URL + 访问日期；区分「已核实 / 推测 / 待核实」。官网原文 > 权威二手 > 待核实。
3. **单一事实源**：方法/范围 = design.md；状态/进度 = 飞书看板；过程 = bAI notes；原始材料 = raw。
4. **对外联络由白纸发起**：AI 不代替白纸给杨老师、雨欣、企业发消息；可代拟草稿。
5. **访谈红线**：先知情同意，再录音/记录；企业未公开数据脱敏后入库；不承诺保密级别以外的事。
6. **不写标准正文**：会议/评审前只做调研与方案对比；标准条款/字段定稿须团队对齐后动笔。
7. 操作纪要追加 `bAI/bAI/wiki/log.md`；详细过程写 `bAI/bAI/notes/2026-10-20-陶瓷数字资产-*-notes.md`。
8. 工具调用失败（lark-cli/检索）如实上报，不静默降级、不假装完成。
