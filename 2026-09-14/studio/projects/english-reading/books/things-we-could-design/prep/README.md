# prep/ — 备课材料（AI 侧答案册）

> **这是 AI 的备课夹，不是白纸的学习材料。** 陪读会话按 `../AGENTS.md`（书级）与 `../../AGENTS.md`（书架级）规则进行，本目录只服务一件事：**白纸发段落之前，AI 已经把功课做好**。

## 使用规则（陪读会话必读）

1. **后置原则**：本目录的逐句分析是批改对照用的参考答案。白纸没划主干、没自己先读之前，**不给看对应分析**（S3–S6 类自划句尤其如此）。
2. **翻译最后给**：`全文忠实翻译` 只在白纸读完整节之后按需给，永远不放前面。
3. **生词候选 ≠ 生词表**：`生词候选` 未与读者校准，**禁止写入 `../vocabulary.md`**（12 词基线保护，4 周后复测 ≤5）。
4. **预出题到点才出**：先只给题目，白纸可「跳过」。
5. **冲突时以白纸的划法为准**：参考分析只是 AI 一家之言，批改是对照，不是审判；结构有歧义的句子（如 ch01-opening 的 S63）不强判。

## 文件命名与结构（v3 深析规格，2026-09-13 白纸两轮加码定调「token 当无限用，重点是仔细」）

- **章文件夹**：`ch<两位章号>/`。文件夹内：
  - `README.md` — 节级索引：小节切分与状态表 / 节内地形 / 全书词频速览（脊柱词 vs 一次性词）/ 检验点规划 / 难点句索引 / 预出题草稿 / 思想家速查 / 全文忠实翻译（最最后）/ 待核事项
  - `P<两位段号>.md` — 每段一份深析（一段一文件，跟白纸发段落的节奏对齐）
- **每句固定结构**（P0x.md 内）：
  1. **朗读分组**——原句加 ｜ 呼吸组标记
  2. **线性串讲 + 预期追踪**——按眼睛看到的顺序逐块讲（表格化），每块标注「此刻大脑的自然预期」与**落空点**（garden-path 预演：坑都在预期落空处）
  3. **主干：是什么 + 怎么找到它**——方法起名（be 动词法 / 成对逗号折叠法 / 省略恢复法 / 同构扫描法…，全书复用）+ 步骤 + **误读版本演示**（常见走错长什么样，含「误读版也通顺」的毒句判据）
  4. **结构树**——折叠版（只骨架）+ 展开版（全挂件），每个挂件标【修饰谁 · 答什么问题】
  5. **全词细讲**——**覆盖全句每个词**：虚词速览（一句话级，但标阅读任务）+ 实词全量，每词含简单英文释义 / 这里之义 vs 常见义 / 词族全家福 / **全书词频**（`scripts/wordfreq.py` 实测）/ **后文原句摘例**（`scripts/wordctx.py` 实测 grep，标章号）/ 中文易混辨析
  6. **语法点**——本句教的通用规则 + 可迁移识别信号
  7. **指代 / 省略 / 熟词僻义**——逐个解决
  8. **翻译**——机翻式直译（反面教材，逐词硬翻让错误可见）+ 忠实译文 + 逐决策点（为什么这么译、直译死在哪）
  9. **这句在干什么**——段内论证角色 + 指代链/伏笔链 + 全书接线（后文哪里回收）
  10. 简单句各节自然收窄，但每项保留标题（哪怕一行）
- 段文件头：**段落论证图**（claim/让步/枢轴流向图）；段文件尾：**复习锚点**（自测题 + `<details>` 折叠答案区）。
- 历史版本：v1 四项简析版 → `temp/archive/prep-v1-ch01-opening-20260913.md`；v2 九项版被 v3 取代（差异：v3 增预期追踪/全词覆盖/后文摘例/直译对照/双视图/锚点答案）。
