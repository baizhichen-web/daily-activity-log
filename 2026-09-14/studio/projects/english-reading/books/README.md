# 书架

> 一本书一个文件夹。**分组用标签，不用文件夹层级**——一本书常同时属于多个分组，而重组分组会让路径失效。
> 开新会话时，贴目标书 `README.md` 里的那段提示词。

## 开新会话怎么说

只需要一句：

```text
【读书空间】按 studio/projects/english-reading/books/AGENTS.md 的开场问询开始。
```

AI 会先读书架索引，再依次问你：今天读哪本 → 从哪继续 → 读多少。**每个问题都带默认答案**，你一句话就能过，也可以直接跳过问询发段落。

## 分组说明

分组是自由标签，随时可加可改，只维护在上面这张表里（AI 负责同步）。
将来书多了想按分组筛选，在这张表里筛即可；不建议改成文件夹层级，理由见文首。

## 新增一本书

开个会话，贴这段（填好尖括号）：

```text
【新增书籍】
书名：<书名>
作者：<作者>
主读本：<纯英文版 epub 路径>
答案册（可选）：<双语版路径>
分组：<标签>
```

AI 会自动跑难度画像（`scripts/epub-stats.py`）、建目录、填档案、登记书架索引，然后把**这本书的会话提示词**交给你。你只需要贴这一段。
