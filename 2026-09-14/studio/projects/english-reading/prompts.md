## 每天流程

1. **你读**：一段英文原文，读到自然断点。不查词、不翻译。
2. **你发我**：把这段原样贴过来（卡住的句子可以标一下）。
3. **我出处理包**（逐句分析 → 最后总结）：
   - **主体·逐句分析**（一句一段，每句四项）：① 主干（主/谓/宾 或 主系表）② 挂件（从句、插入语、介词短语挂在哪、修饰谁）③ 当场点掉（省略、指代、熟词僻义）④ 这句在干什么（主题/铺垫/让步/转折/例证）
   - **结尾·总结**（全部句子分析完才出）：① 关键词表（超出四级的词 + 你标出的词；熟词僻义标「常见义 ≠ 这里的义」）② 难点句索引（只回标）③ 全文翻译（**完完全全按原文翻译**，**放最最后**）
4. **检验 + 笔记**：到进度点（每小节末；超约 1,500 词的节中途加一次）我出 3 道英文理解题（先只给题目）→ 你答我批 → **你用自己的话写几句笔记** → 我整理成知识库卡给你过目 → 你说「入库」我写进 bAI。说「要词测」再加 8 道词测；到点可回「跳过」或「再读一段」。

**两条纪律**：① 逐句分析只讲结构与关系，不给整句译文；② 全文翻译放最最后——先看英文原文，卡住了才看中文。

## 提示词

### 主用｜处理包

```text
我在读《Things We Could Design》(Ron Wakkary)。下面是我刚读的一段原文。

先逐句分析，一句一段，每句给四项：
① 主干（主/谓/宾 或 主系表）
② 挂件（从句、插入语、介词短语挂在哪、修饰谁）
③ 当场点掉（省略、指代、熟词僻义）
④ 这句在干什么（主题/铺垫/让步/转折/例证，一句话）

全部句子分析完，再出总结，顺序固定：
① 关键词表：超出四级的词 + 我标出的词，英文简释 + 中文；熟词僻义标「常见义 ≠ 这里的义」
② 难点句索引：哪几句结构绕（只回标）
③ 全文翻译：完完全全按原文翻译，放最最后

逐句分析只讲结构，不要整句译文。不要补充我没问的内容。

原文：
「粘贴」
```

### 长句拆解

```text
拆这一句，按顺序：① 主句主干（主/谓/宾）② 每个从句、插入语挂在哪、修饰谁 ③ 省略成分补全。拆完先停，让我自己找一遍主干再给答案。
句子：「粘贴」
```

### 理解检验

```text
我用英文复述了刚才读的一段。请只做三件事：① 我漏掉的关键论点 ② 我理解偏的地方 ③ 我表达上更自然的说法（只改我写错的，不要替我重写整段）。不要总结原文。
我的复述：「粘贴」
```

### 单词测试

```text
就这段内容出 8 道词测题：5 道「英文词→中文」、2 道「中文→英文」、1 道熟词僻义辨析。先只给题目，我答完你再给答案和批改。
```
