# 产品调研：无感 AI 阅读助手（2026-09-10）

## 白纸的规格

- 在**既有阅读器**里完成，不切换应用
- AI **已经拥有这本书的上下文**
- **选中即操作**——不需要"把段落发给 AI"，也不需要"我问一句 AI 答一句"
- 三个动作：① 句子拆解 ② 词义解释（选中单词即出）③ 语法解析（结合固定语境）
- 检验 = 直接用英文回答问题

## 核心判断：价值分水岭是"AI 能看到多少书"

| 档 | AI 拿到的上下文 | 产品价值 |
| --- | --- | --- |
| 1 | 只有选中段落 | 聊天框——只省摩擦，不增能力 |
| 2 | 段落 + 前后文 / 整章 | 语境化解释（能答"这里为什么用这个时态""这段在讲什么"） |
| 3 | 全书 + 你的划线 | 个性化陪读（能答"这个概念在全书里怎么演变"） |

**白纸的三个动作，第 2 档就够了**——拆句、词义、语法解析需要的语境是句子和相邻段落，不是全书。第 3 档服务的是另一类问题（概念在全书的脉络），不该混进来。

## Calibre 的硬限制（源码实测，2026-09-10）

1. **AI 只拿到书名 + 作者 + 选中文本**。`viewer/llm.py` 的 `create_initial_messages` 注入的系统消息只有 `I am currently reading the book: <书名> by <作者>`，没有正文。
2. **改变选中文本会清空对话历史**。`llm.py: update_with_text()` 里，选中文本一变就 `clear_current_conversation()`（`conversation_history = ConversationHistory()`）。
   → 所以"先贴一章、再选段提问"这条补法**不成立**——选中段一变，之前贴的内容就没了。
   → 每个选中段落都是全新对话。
3. 同一段选中期间多轮对话是保留的（可以追问）。

**结论：Calibre 现在这个形态，确实就是"每个选中段落一个聊天框"。** 与直接开别的 AI 相比，区别只有三条摩擦：省掉复制粘贴+切窗口、省掉每次打提示词、回答能一键存回书里。

## 产品地图（按"AI 能看到多少书"排）

| 产品 | AI 看到多少 | 阅读器内 | Windows | 备注 |
| --- | --- | --- | --- | --- |
| Kindle Ask this Book | 全书 | ✅ | 部分 | 生态封闭 |
| 微信读书 AI 问书 | 全书 | ✅ | 部分 | 书须在其平台 |
| **Marginalia**（开源，AGPL-3.0） | **整章** + 读到哪 | ✅ | ❌ 仅 macOS/Linux | Readest fork + Pi + Tauri；用 Claude Code / Codex 凭据 |
| Calibre 9.13（配置后） | 书名 + 选中段 | ✅ | ✅ | 见 `calibre-setup.md` |
| Weave EPUB AI Reader（Obsidian 插件） | 选中段 | ✅ | ✅ | 仅 DeepSeek；4 步操作 |
| Mythos | 部分 | ✅ | ❌ macOS/iPad | 选中→浮动面板，AI 猜意图 |
| Readest | **无 AI 对话**（只有 TTS / DeepL 翻译 / 维基查词） | — | ✅ | 能连 Calibre 书库（OPDS） |
| NotebookLM / LocalRAG / Myreader | 全书 | ❌ 不是阅读器 | Web | 上传书→问答，带引用 |

**关键发现：Marginalia 就是白纸描述的那个产品**——选中段落 → 右侧对话，AI 拿整章文本当上下文，还知道你读到哪。但**没有 Windows 版**。

**Readest 的 GitHub 上有一条尚未实现的功能请求（issue #1741，2025-08）**：让聊天机器人知道书的上下文。说明需求真实存在，且通用阅读器普遍还没做。

## 可选的下一步

| 路 | 做法 | 代价 |
| --- | --- | --- |
| **1（推荐）** | Calibre + **选中时多划一点**（把前后一两段一起选上） | 零成本；立刻把第 1 档拉到第 2 档 |
| 2 | 用 ZCode 当那个 AI——epub 在工作区，能读全书，选中段落贴过来在全书语境里答 | 有复制粘贴，正是想避免的摩擦 |
| 3 | 自建/改造：Marginalia 是 Readest fork + Pi + Tauri，理论上能编 Windows 版 | 工程量不小，AGPL-3.0 |
| 4 | 等 Readest issue #1741 落地 | 不可控 |

**推荐先做 1。** "固定语境下的语法解析"要的是相邻段落，不是全书；把选中范围扩大到一两段，Calibre 就能满足。全书级的问题（概念脉络）另找场合问，不混进阅读流程。
