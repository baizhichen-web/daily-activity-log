## 组件乐高 · 按需取件指南（2026-08-31 起替代整库克隆）

> 2026-08-30 曾建 temp/refs 整库浅克隆区（7 库 64MB）；2026-08-31 白纸问"会不会太重、有不克隆的法子吗"→ **实测单文件直取全通，默认不克隆**：用时拉清单 → 拉单件 → 三道翻译 → 进 web/src。**react-bits 例外保留本地**（MVP 指定参考源，开工要多件比对，且站点 JS 渲染最难在线翻源码；不需要时可同样删，重取零成本）

| 库 | 在线清单（机器可读） | 单件直取 | 依赖饮食（翻译） |
|---|---|---|---|
| beUI（I-08） | `https://beui.dev/r/registry.json` 或其 SKILL.md 工作流 | `raw.githubusercontent.com/starc007/ui-components/main/components/motion/<件>.tsx` | Motion+Tailwind → 翻译管线；agents 族不进个人站 |
| rare-ui（I-09） | `raw.githubusercontent.com/swamimalode07/rare-ui/main/registry.json`（17 件） | registry.json 内 files 路径 → raw 直取 | Motion+Tailwind → 翻译管线 |
| React Bits ⭐（本地 `temp/refs/react-bits/`） | `src/content/` 目录即清单 | 本地直读；在线=`raw.../reactbits/dev/main/src/content/<类目>/<组件>/` | 混合——挑纯 CSS/GSAP 件最省 |
| motion-primitives / fancy / shadcn-studio / fluid-functionalism（不克隆） | GitHub 目录页 / `gh api repos/<owner>/<repo>/contents/<path>` | `raw.githubusercontent.com/<owner>/<repo>/main/<path>`（I-07 弹簧三档 0.08/0.16/0.24s 在其 animation-guidelines.md） | 各自翻译管线同上 |

**取件通道**（2026-08-31 本机实测）：① python urllib 拉 raw.githubusercontent.com——⚠️SSL 握手偶发抽风，**必须带重试**；② `gh api repos/<owner>/<repo>/contents/<path>`（已登录，稳）；③ shadcn 查看模式 `npx shadcn@latest view @beui/<slug>`（看码不装；直装=进 shadcn 基建，与零依赖 MVP 不符，只当索引用）

**改造铁律**（接 Product.md §8，不变）：抄「动效机制」，过三道翻译——FM → 自建 spring.ts、Tailwind 类名 → tokens.css、图标/字体 → 自有；许可留痕（文件头注释来源仓库+MIT）。

**急用多件时的重建命令**：`git clone --depth 1 https://github.com/<owner>/<repo> temp/refs/<name>` 并删 `.git`（react-bits 另删 `public/`）。
