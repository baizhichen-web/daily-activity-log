## 每轮交付验收清单

**产品语义（来自 Product-补充节）**
- [ ] 点卡片 = 打开原书那一页，划线定位正确且自动居中；点卡片不翻页
- [ ] 卡片只含钩子：划线原文 + 书名/章节/日期 meta；无 AI 总结、无预置上下文
- [ ] 翻卡走按钮/键盘/滑动，与点卡不冲突
- [ ] 无通知、无徽章、无红点、无 gamification
- [ ] 记录 → `阅读笔记-<书名>.md` 追加成功、格式不变；progress.json 零迁移兼容
- [ ] Calibre 书库全程只读；PDF-only 书回原文失败有回退提示不崩

**视觉（来自设计基因库）**
- [ ] 基因封闭：实现中的视觉决策 ⊆ 基因库；违反即回改
- [ ] 强调色唯一（印泥红）；荧光底只涂钩子；正文墨字对比度 ≥ 4.5:1
- [ ] 状态只用印章表达（G-17），无彩底按钮态

**动效（Evaluator 通用基线「≤200ms」的项目实例化）**
- [ ] 反馈/循环动效 ≤200ms；一次性定位叙事（荧光呼吸）≤400ms 且每卡至多一次
- [ ] 无弹跳、无闪烁、无庆祝动效

**可用性**
- [ ] 键盘全可达：←→/空格 翻卡、Enter 回原文、R 记录、A 已吸收、F 收藏、Esc 关弹层/回卡片
- [ ] 桌面 1280/1440/1920 三档宽度布局不破（手机后置，仅保可用）

## 实现纪律（v0.9 夜间验证发现 · AI 提案，待白纸复核后转正）

1. 程序化瞬时定位（滚动到划线）**不得**用 `behavior:'auto'`——它会被 CSS `scroll-behavior:smooth` 改写回平滑，导致定位时序不可靠；要么显式 `behavior:'instant'`，要么不给滚动容器写 CSS smooth（本次曾致验收抖动 2 项）
2. 快捷键触发浮层/动作**必须 `preventDefault`**，防字符漏进随后获焦的输入框（R 键曾漏字）
3. 状态组件显隐走**单一 class 链路**（本副本：`empty-mode`/`set`/`on`），禁止多处各自开关同一视觉（G-17/G-22 联动的教训）
4. 自动化验收断言对平滑滚动/动画**必须轮询至稳定**，不许定长 sleep——抖动的从来是测试，不是应用（本条同时是测试纪律）
