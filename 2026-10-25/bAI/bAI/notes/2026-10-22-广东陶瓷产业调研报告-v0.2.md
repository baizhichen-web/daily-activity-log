## 摘要（一页）

**广东陶瓷的「设计—制造」不是一条单向文件流，而是「总部设计＋异地制造＋打样对色＋版权登记」四段式回路。**设计在佛山/潮州总部与外部设计机构产生（图案、花色、器型），制造大量外迁到清远、肇庆、藤县基地；中间靠**打样—对色—留样—首件确认**这组人工密集动作，把设计"翻译"成可量产参数。数字化（喷墨、3D 快速制模、MES、AI 质检）正把一部分经验固化为数据，但**版辊透墨量、釉料配方、烧成曲线、留样签样仍是纸质＋经验＋微信并存**。

**三个可支撑标准立项的判断**：

1. **断点在交接层，不在文件格式**。制造侧已被头部企业系统化（蒙娜丽莎 AI 质检 99.8%、新明珠"一砖一证"、金意陶采集率 93%+），但 22 项「设计—制造交接数据」中**仅 2 项被系统管理**（且都在喷墨装备侧、封闭于设备商体系），**8 项完全靠纸质/微信/经验**——权利状态、保密等级、网版参数、分道留样、首件签认、ECN 变更。产业平台方（众陶联 2024）原话："已改造工厂仍有很多没有打通的数字接口，上下游存在很多堵点。"
2. **广东提供了完整的政策与制度抓手**：佛府办函〔2022〕183 号明文要求陶瓷"推动隐形生产经验数据化、软件化"；潮州目标 2028 年规上企业数字化全覆盖；行业"十五五"定 2030 年建陶/卫陶关键工序数控化率 85%/70%。权利侧基础设施成熟（佛山 2024 年著作权登记 24338 件全省首位、潮州快维中心外观专利 10 个工作日授权、中潮基地版权登记 5191 件）。
3. **设计端的线上撮合/复用完全缺位**：四条对接路径（政府对接会、云设计平台、反向飞地、赛事展会）全部线下为主，唯一规模化的线上撮合在供应链采购端（众陶联），不在设计端。
4. **标准通道已经清楚**（2026-10-22 补）：中陶协是 SAC/TC405 主任单位但该标委会只覆盖日用陶瓷，全品类规范不宜挂靠；**最现实路径是中陶协团体标准快通道（T/CCIA）**——协会 2023 年即完成 6 项团标、2026 年仍在征集计划，且明示团标“为国家标准、行业标准的制定提供基本的应用数据支持”，与“团标先行→行标准备”双轨完全吻合。

**标准建议**：单列「设计—制造交接数据包」6 组 22 项字段（每项要求"版本＋责任人＋判定结果"），三条优先条款——**分道留样入标**、**"条件"做成可校验的适用边界**、**OEM/ODM 来样单列权利审查**。

**产业链**：原料 → 坯料 → 成型 → 施釉 → 装饰 → 烧成 → 冷加工 → 包装/花纸 → 物流 → 会展 → 应用。广东供给最完整的是**装备（科达、恒力泰）、釉料/墨水（道氏、康立泰）、色料、花纸、模具**——"设计落地所需的上游"省内即可配齐。

**代表企业**（13 家，详见分线 note）：蒙娜丽莎、东鹏、新明珠、箭牌、宏宇（佛山建陶/卫浴）；科达制造、道氏技术、恒力泰（装备/材料）；三环集团（电子陶瓷）；松发、顺祥、安彼（潮州日用/卫浴）；顺络电子、信柏精密（工业陶瓷）。

## 4. 工艺链与关键参数（五类）

| 品类 | 代表工序链 | 已核实关键参数 |
| --- | --- | --- |
| 建筑陶瓷/岩板 | 原料→球磨除铁→喷雾造粒→压制成型→干燥→施釉→喷墨/丝网/辊筒印花→烧成→冷加工→检选 | 烧成 **1180–1220℃**、最高 ≤1250℃；573℃ 石英 α-β 转变体积突变 **10.82%**；吸水率界值见 GB/T 4100-2015 附录 G/H；蒙娜丽莎产线自动化率 90% |
| 卫生陶瓷 | 高压注浆→修坯→施釉→烧成→检选 | 高压注浆 **2.0–2.5 MPa**、周期 **10–16 min/件**；烧成 **1175–1190℃、14–17 h**；合格率 >95% |
| 日用陶瓷（潮州） | 滚压/注浆成型→施釉→贴花/手绘→烧成→烤花 | 工序链部分核实；参数多为行业口径，逐项待核 |
| 艺术陶瓷（石湾） | 成型→施釉→龙窑烧成 | 龙窑"三日火"：挤火 12h→900–1000℃，上火 6h→最高 **1300℃**，冷却 **30h** |
| 工业/电子陶瓷 | 流延/等静压→烧结→加工→检测 | 参数几乎全缺，建议访谈补 |

**设计参数 → 制造参数的映射**（标准"内容/条件"字段的直接依据）：

- 花色清晰度 → 喷墨 dpi（800）与釉层厚度（0.2–0.3 mm）
- 质感 → 施釉量（420 g/m²）、面釉配方、抛光段
- 色差 → 烧成带位置（1180–1220℃ 内）、气氛、原料除铁
- 变形 → 收缩率（岩板可达 11%）、升降温曲线、辊棒支撑
- 釉色（艺术瓷）→ 窑位＋最高温 1300℃＋柴灰

**数据化程度分层**：建陶头部（自动化 90%、全流程数字化）＞卫生陶瓷（机械手施釉、高压注浆）＞日用瓷（还原焰辊道窑）＞艺术瓷（人工龙窑）＞电子陶瓷（智能车间但参数保密）。**标准不能假设全行业都有 MES 数据，需分档。**

> 缺口：色差 ΔE 判定阈值、岩板烧成周期与压机吨位、GB 6952 现行版限值、潮州日用/艺术瓷参数、三环烧结与流延参数、各品类在线检测配置率。

## 5. 设计—制造怎么连接（核心）

### 5.1 六步回路

```
① 需求/输入：客户来样(OEM/ODM) · 市场趋势 · 展会/竞品 · 内部产品规划
② 设计（多在总部/外部机构）：企业设计部(图案/花色/器型) ＋ 研发部(新工艺/新配方)；
   外部设计公司 / 工业设计城 / 驻厂设计师
③ 设计—工艺会签（最易断）：设计稿 → 工艺可行性判断（烧成收缩/釉料发色/喷墨通道/网版目数/模具结构）
   产出：可生产版设计 + 工艺卡草案 + 打样申请
④ 打样/中试：小样 → 中试(手喷/小压机) → 上线试产 → 分道留样 → 对色 → 签样
⑤ 量产（常在外地基地）：成型 → 施釉 → 喷墨/丝网/辊筒印花 → 烧成 → 检选(色差/尺寸/变形)
⑥ 反馈回设计：色差/变形/批次不稳 → 改设计或改工艺 → 新版本（版本管理常缺失）
```

**两个闸门**：③会签、④打样对色。标准若只覆盖②的文件格式、不覆盖③④的判定与留证，接口仍然断。

### 5.2 三套并行的"文件语言"

| 语言 | 内容 |
| --- | --- |
| 设计语言 | 分层 PSD/AI → 多通道配色 → RGB → **ICC 曲线** → 按机台裁剪 |
| 机台语言 | 喷墨文件（机台型号/幅宽/通道映射）、网版目数与**透墨量**、激光雕刻硅胶辊筒 |
| 模具语言 | 3D → 按烧成收缩**放尺** → 原胎模 → 石膏试验工作模 → 树脂模 |

### 5.3 接口人不是系统，是岗位

企业内"产品经理/设计经理"就是接口人：东鹏岩板产品经理 JD 明写"试制打样、确认颜色与工艺、协助各部门确认量产质量和颜色"；康立泰设计经理 JD 要求"喷墨/柔光釉/干粒/立体数码工艺适配，全程负责打样、调色及量产迭代"，并要求"沉淀研发素材与标准化设计体系"。

### 5.4 打样与对色的硬证据

- 2006 年陶城报《瓷质仿古砖色差》：上线至少对 **6 种颜色**、**分道留样**、中试 **4–5 次**；手喷改水刀即偏浅；改网透墨量导致反复。
- 卫浴：2007/2012 年"快模＋烧成收缩专家数据库"把开发周期从 1.5–2 月/6 月压到 **1 周/1 月内**。
- 现状痛点：分道留样执行率低（"到 6 月只有约四分之一产品重定标准样"）、对色靠技术员习惯、印花线条干湿靠"花机技术员的感觉"。

### 5.5 七个冲突点

1. 设计稿颜色 ≠ 烧成颜色（需 ICC＋分道留样＋对色）
2. 工艺反过来改设计（透墨量、施釉方式改变最终颜色/肌理）
3. 收缩/变形导致造型走样（必须放尺）
4. 批次色差与跨基地稳定性（"近一半大生产上线产品比标准样浅"）
5. 小单快反 vs 清洗换色成本（转产越多色差风险越大）
6. 设计端与制造端异地（寄样成为关键路径）[推测]
7. 权利冲突：OEM 来样侵权，**受托生产方被判共同担责、赔 25 万元**（佛山判例）

## 6. 数字化现况：制造侧系统化，交接侧空白

### 6.1 断层结构

- **制造侧已系统化**：蒙娜丽莎 AI 质检 99.8%、排产 7 天→1 天、智能仿版 7 天→5 分钟；新明珠 5G 全连接工厂＋20 通道全数码喷绘无水釉线＋"一砖一证"；金意陶采集率 93%+、"一单到底"；东鹏 2012 年数字化设计研发平台（烧成专家数据库）；峰华卓立 3D 打印砂模（研发成本 −40%）。
- **接口没打通**：众陶联白皮书（2024）"已改造工厂仍有很多没有打通的数字接口，上下游存在很多堵点"；代表性企业 40.74% 仅局部部署、14.81% 尚未开展。
- **22 项交接数据覆盖判定**：已被系统管 **2 项**（分色方案、喷墨文件——均喷墨装备侧）｜部分覆盖 **12 项**｜仍靠纸质/微信/经验 **8 项**（权利状态 A4、保密等级 A5、网版参数 B9、分道留样 B10、模具修改记录 C14、工艺适配说明 D17、首件签认 E19、ECN 变更 F21）。
- **结构判断**：数字化强项全在制造执行与质检，空白全在**权利与留证**＋变更管理。

## 7. 设计与企业对接的平台和机制

| 平台/机构 | 关键事实 |

## 8. 对标准的意义（本报告核心产出）

### 8.1 建议单列「设计—制造交接数据包（D2M Handoff Package）」

6 组 22 项，**每条要求"版本＋责任人＋判定结果"**：

| 组 | 字段 |
| --- | --- |
| **A 设计与权利** | ①设计编号/版本/生效日期 ②设计类型（原创/改良/客户来样/仿石仿木）③花型源文件（分层 PSD/AI 命名规则、图层规范、分辨率下限）④权利状态（自有/客户授权/第三方；版权登记号；授权范围与期限）⑤保密等级与访问权限 |
| **B 色彩与印花** | ⑥目标色与色差容限（ΔE 或目测等级、对色光源）⑦分色方案（通道数、墨量、ICC 版本）⑧喷墨文件（机台型号/幅宽/通道映射/版本）⑨网版/版辊参数（目数、透墨量、雕刻深度、版号）⑩色卡/标准样编号（分道留样清单） |
| **C 造型与模具** | ⑪3D 模型（格式/单位/基准/版本）⑫收缩放尺系数（按泥料/窑炉/器型）⑬模具编号与工序链 ⑭模具修改记录 |
| **D 工艺与 BOM** | ⑮工艺卡（坯/釉配方代号、比重、流速、细度、施釉量、烧成曲线、窑速）⑯BOM（坯料/釉料/墨水/色料/网版/包装，含替代料）⑰工艺适配说明（该设计对施釉/印花方式的限制） |
| **E 打样与验证** | ⑱打样轮次记录（轮次/日期/样品编号/与标准样差异/修改点）⑲首件确认/签样（签样人、客户确认、确认样编号）⑳判定结论（合格/让步接收/返工/放弃＋依据） |
| **F 变更与追溯** | ㉑设计变更单 ECN（原因、影响范围、需重做的打样/模具/网版）㉒批次关联（设计版本↔工艺参数↔批次↔检选结果） |

**数字化覆盖现状**：2 项已被系统管（⑦⑧，装备侧）｜12 项部分覆盖｜8 项空白（④⑤⑨⑩⑭⑰⑲㉑）——空白即标准价值所在。

### 8.2 六字段承接

| 六字段 | 在本主题下的定义 | 可直接进条文的要点 |
| --- | --- | --- |
| 对象 | 被管理的设计—制造数据单元 | "花型设计包""喷墨分色文件""原胎模数据""打样记录""首件确认单" |
| 来源 | 数据产生者与产生环节 | 设计部/研发中心/外部设计公司/驻厂设计师/客户来样；打样由技术部或产品经理发起 |
| 内容 | 必备项与格式 | 22 项接口数据；格式写死（PSD 分层、ICC 版本、STEP、网版目数与透墨量、ΔE 容限） |
| 条件 | 数据成立/有效的边界 | 适用泥料釉料体系、窑炉与烧成曲线、机台型号与通道、版权地域与期限；**换条件必须重新验证**（手喷改水刀须重打样） |
| 使用 | 谁在什么权限下怎么用 | 设计→分色→制版→打样→量产→检选；外发须授权+水印；客户来样先做权利审查；变更走 ECN 并回溯批次 |
| 质量 | 判定依据与留证 | 色差（ΔE/目测＋光源）、尺寸变形、打样轮次是否收敛、首件是否签认、留样是否齐全、变更是否闭环；**判定必须留样＋留记录** |

### 8.3 三条优先条款建议

1. **把"分道留样"写进标准**：留样对象（坯/底釉/各道印花/成品）、留样期限、对色条件。成本最低、最能解决色差争议；2006 年即有企业实践但执行率低。
2. **把"条件"做成可校验的"适用边界"**：同一设计文件在不同施釉方式/窑炉/基地不可默认可复用；换条件即重打样并留证。
3. **给 OEM/ODM 来样单独一条**：记录"客户图样来源＋授权声明＋权利审查结论"，以佛山判例（受托方共同担责 25 万元）作风险说明。

### 8.4 配套建议（来自数字化与平台两条线）

- **切口在交接层而非产品层**：不与任何在产系统冲突，正好填补系统间的"接口真空"。
- **对接而非重复造轮子**：喷墨装备生态（DPI Master"一砖一码"、TIS 智能调色、对接 SAP/ERP/MES）已把分色/喷墨做成设备参数——标准应引用其接口形态，规定"交接数据包的机器可读最小集"，而不是另立文件格式。
- **条件字段做保密分级而非要求上报原值**：配方、烧成曲线、压机参数是陶企核心机密；标准只登记"参数存在性/版本/责任人/可用范围"。
- **质量字段挂第三方节点**：CCC 认证、国家级研发中心、绿色工厂、质检记录可作为默认证据链。
- **承接区/贴牌场景单列权属边界**：肇庆/江门/清远/云浮以 ODM 为主，品牌方设计文件与工厂工艺参数两地分离，标准需明确资产归属与披露口径（会展为合规关口）。

### 11.4 对标准路径的含义

1. **最现实路径＝中陶协团体标准快通道**（T/CCIA），与“团标先行→行标准备”双轨吻合；协会自身已在推“标准数字化”机制创新。
2. **中国工业设计协会 × 中陶协联合**是合理架构：CCDA 出“设计应用/数据管理”方法论，中陶协出陶瓷行业落地与归口——需在问题清单里问杨老师两协会的实际分工。
3. **质量字段应引用而非另建**：GB/T 45817-2025《消费品质量分级 陶瓷砖》（2025-12-01 实施，5A/4A/3A，已推动 30 余条产线改造）＋环办大气〔2026〕2 号绩效分级（A/B/C/D/A+，全国统一平台，与金融税收激励挂钩）已构成事实分级体系。
4. **使用字段可挂靠职业评价基地**（35+16 家）与版权/快维体系，形成“确权—复用—维权”链路。
5. **工艺/能耗数据已有政府数据底座**（全国统一绩效分级平台＋GB/T 32151.52-2025 的数据质量管理范式），标准不应重复建设制造端工艺数据字段，应聚焦**设计资产侧**并定义与制造端数据的引用关系。

## 12. 2023→2026 行业剧变（立项论证必须适配）

| # | 变化 | 数据 |
| --- | --- | --- |
| 1 | **产量断崖** | 建陶从 2016 年峰值 102.6 亿㎡跌至 2025 年 **48.60 亿㎡（−17.8%）**，回到 2007 年前水平 |
| 2 | **利润逻辑反转** | 2023 年全行业利润 +21.6% 的“企稳回升”叙事 → 2025 年利润总额/利润率双降、亏损面扩大；9 家上市陶企营收合计超 300 亿元、**净利润合计不足 10 亿元** |
| 3 | **产能过剩显性化** | 2024 年产能 122.1 亿㎡ vs 有效需求约 50 亿㎡，一半以上产能闲置 |
| 4 | **协会换届与新议程** | 2024-12 换届；《陶瓷工业“十五五”规划》启动编制；数字化进入协会正式议程 |
| 5 | **质量分级国标落地** | GB/T 45817-2025（2025-12-01 实施） |
| 6 | **环保绩效分级制度化升级** | 环办大气〔2026〕2 号（三部门联合印发）：“1+1+1+N”体系、A/B/C/D+A+ 级、全国统一平台、**与金融税收激励挂钩** |
| 7 | **双碳进入实施期** | GB/T 32151.52-2025（2025-12-01 实施）；《中国陶瓷行业碳中和路径…报告（2024版）》 |
| 8 | **出口模式转折** | 2025 年陶瓷砖出口量 5.67 亿㎡（−5.29%）、出口额 30.69 亿美元（−4.40%）；从“产品出海”转向“产能出海” |
| 9 | **服务化转型** | T/CBCSA 75-2025《陶瓷砖密缝粘贴工程技术规程》（行业首部服务性标准）；《深入推动服务型制造创新发展实施方案（2025—2028 年）》 |
| 10 | **产区集中度** | 江西、广东、福建、广西、山东、四川六省占全国建陶产量 **69.55%**（2025） |

**对标准的两点直接影响**：

1. **行业下行 ≠ 标准没价值，反而更值**：产能过剩＋利润承压＋质量分级与绩效分级同时收紧，企业必须靠“设计/花面/IP 差异化”和“数据化管理降本”找活路——**设计资产与接口数据的标准化，正是下行期少数能增值的环节**。立项论证应把这条写进“必要性”。
2. **口径必须分线**：建陶（收缩最快，规上 993 家）与日用瓷/艺术瓷（相对韧性、数据稀缺）不可混谈；标准适用范围建议明确“建筑陶瓷＋日用陶瓷”两条主线，艺术/文创线用轻量口径（与 §9 缺口、§10 下一步衔接）。
