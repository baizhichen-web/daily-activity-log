## 怎么启动那个会话

见 `SESSION-PROMPT.md`。把里面 `====` 之间的内容整段复制到新的 ZCode 会话开头即可，那边会自己读这个目录。

## 目录职责

| 路径 | 谁写 | 内容 |
|---|---|---|
| `raw/` | **白纸** | 报告原文（PDF / 网页存档 / Markdown） |
| `notes/` | AI | 每份报告一份分析笔记 |
| `notes/文献综合.md` | AI | 全部处理完后的合并产出 |
| `SOURCES.md` | 双方 | 来源清单与元数据 |

## 白纸投料时要做的事

1. 文件放进 `raw/`，**文件名带年份与机构**（如 `2025-WEF-Future-of-Jobs-Report.pdf`）
2. 在 `SOURCES.md` 追加一行，注明：来源链接、获取日期、**你判断的证据类型**（一手数据 / 二手综述 / 专家判断 / 媒体报道）

## 这条线要找的四类材料（按价值排序）

| 优先级 | 类型 | 为什么 |
|---|---|---|
| ★★★ | **同一机构的跨年份报告**（WEF 2020 vs 2025） | 唯一能把"变化"量化的文献证据，**性价比最高** |
| ★★☆ | 政府与行业组织报告（OECD、教育部、工信部、IDEO/Design Council 年度报告） | 口径稳定，引用价值高 |
| ★★☆ | 学术综述（AI 与设计教育、设计能力框架） | 可作理论支撑，注意区分综述与实证 |
| ★☆ | 媒体报道与实践者文章（公众号、知乎、行业媒体） | **证据等级最低**，只能当线索，且要在笔记里标死 |

## 已知的一条重要线索（别重复劳动）

报告里高频的 **"AI 素养""AI 思维"**，在 329 条真实 JD 里几乎找不到这三个词。JD 要的是具体动作（"用 Claude Code 作为创作伙伴"等）。

**文献会话的任务是确认这是系统现象还是巧合**——需要再找到第二例、第三例。详见 `../04-综合/交叉矩阵.md` 的"差值 ①"。

## 硬约束

- **联网检索统一走宿主原生工具**：`web_search`（一次可给 1–4 个 query）+ `web_fetch`（抓正文）；站点/语言/时间范围把 `site:`、`lang:`、`after:` 写进 query。超过 4 组查询分多次调用。anysearch 已于 2026-10-20 退役。
- 不整站爬取报告站点，优先走官方 PDF 或一手发布页。
- 引用必须到**具体某份报告的某页/某节**，不能只写报告名。
- **不许替白纸下结论。** 产出的是"报告 A 第 12 页主张 X"，不是"所以学生需要 Y"。
