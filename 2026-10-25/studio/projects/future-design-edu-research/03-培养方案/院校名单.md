## ⚠️ 两个必须说清的问题

### 问题一：QS 艺术与设计是宽口径，排名高 ≠ 对未来设计学院有对标价值

QS 这个学科榜是**艺术与设计大口径**，前几名（RCA #1、UAL #2、New School #3）偏纯美术、时装、视觉传达。而未来设计学院的取向是**偏硬件、重动手、强调 AI 与未来设计结合**。

**结论：QS 定的是"标杆合法性"（凭什么选这几所），不是"对标相关性"。** 名单要在 QS 基础上过一道相关性筛选。

### 问题二：培养方案原文能不能拿到，比排名更要紧

排名高但拿不到方案原文的学校，选了也是白搭。实测（2026-10-01，走代理探测 Wayback）：

| 探测对象 | 结果 |
|---|---|
| 同济大学研究生院 `yz.tongji.edu.cn` | ✅ 有 2018 / 2019 存档 |
| 同济大学主站 | ✅ 有 2019 存档 |
| 清华大学研究生院 `yz.tsinghua.edu.cn` | ✅ 有 2018 存档 |
| 中央美术学院 `www.cafa.edu.cn` | ✅ 有 2019 存档 |
| MIT 课程目录 `catalog.mit.edu` | ✅ 有 2018 存档 |
| Royal College of Art 主站 | ❌ 无存档 |
| Imperial College 硕士课程页 | ❌ 无存档 |

**这个结果有点反直觉：中国大陆高校的正式培养方案 PDF（研究生院发布）反而有历史存档，海外学校的 course bulletin 很多没有。** 原因是国内高校有明确的"研究生院 → 培养方案"公开发布制度，海外学校把同样的信息散在 course pages 和 handbook 里，URL 变动频繁。

| MIT 本体 catalog | `catalog.mit.edu` | ✅ 有 2018 存档 |

### 从两轮探测里得出的规律（比排名有用）

**存档可用性跟学校排名、国别都没关系，只取决于"那份文档有没有一个稳定的、被长期引用的 URL"。**

- 有**年度制课程目录**的学校（MIT `catalog.mit.edu`）→ 存档好，因为 URL 每年不变、每年被抓
- 只有**具体专业页**的学校（CMU HCI、Polimi、MIT Design）→ 存档差，因为页面会改版、改路径
- 中国的**研究生院培养方案栏目** → 存档好，因为是制度化公开发布

**选校因此应加第三条标准：优先选"有稳定课程目录/培养方案栏目"的学校，而不是只看 QS 排名。** QS 排名第一但只有零散 course pages 的学校（这里指 RCA），实际采集成本远高于收益。

## 采集时的注意事项

**中国大陆高校的 URL 是 URL 编码的中文**，CDX 返回的结果需要解码后再过滤，否则 grep 不到"培养方案"。

已验证可用的两条命令（**必须走代理，直连 HTTP 000**）：

```bash
# 快速判断某页有没有存档
curl -s -x http://127.0.0.1:7897 "http://archive.org/wayback/available?url=<URL>&timestamp=2018"

# 列某站域下所有被存档的 URL（matchType=domain 必加，否则只返回首页）
curl -s -x http://127.0.0.1:7897 "http://web.archive.org/cdx/search/cdx?url=<domain>&matchType=domain&output=json&collapse=urlkey&limit=200"
```

> 踩过的坑：写 `url=yz.tongji.edu.cn*` 只会返回首页附近的记录，**必须用 `matchType=domain`**。

**每所学校的最低要求：至少两个时间点**（例如 2018 + 2026）。只有一个版本就退化成横截面，"时代特征"这个立论直接塌掉。宁可少收两所学校，也不能每所只收一版。
