## 3. 这几所「缺」的性质不同（事实层区分）

- **判据失效型**：Polimi —— 证据在库里，是我的关键词判据（ECTS）不适用当地学分单位（CFU）。属于**我的方法问题，不是采集问题**。
- **粒度不够型**：江南、清华 —— 采到的是学位点介绍 / 招生专业目录 / 校级通则，不是课程清单。（**CMU 已由国外批次会话补出课程层**，见第 2 节 CMU 行）
- ~~张冠李戴型：央美~~ **该判断已于 2026-10-04 被推翻**：设计学的学位授权点建设年度报告**本身就带课程表**（2022 版 20 行、2024 版 39 行），见第 2 节央美行。
- **通道不可达型**：中国美院 —— 三个子域 DNS 不可达；**当前版未到手**，但**历史版已到手 4 个时间点**，见第 2 节国美行。
- **注意**：本表第 2 节各行是按「当时扫描结果」写的，**已有三行被后续采集推翻并就地修正**（CMU / 央美 / 国美 / UAL）。引用本表时请以各行当前的「已修正/已更新」说明为准。

## 5. 清华 / 浙大 采集回报后的补充事实（2026-10-04，子代理回报）

- **清华大学美术学院**：课程层**未到手**。官方《2023 研究生培养方案汇编》PDF 全在 `cloud.tsinghua.edu.cn/seafhttp/…`，直链一律 **403 Access token not found**（需 Seafile 分享会话），且该域 Wayback **零存档**；研究生院三级栏目（培养要求与规定 / 课程与教学 / 培养项目推介）均无各专业方案。公开可得的只有**招生专业目录**（2024 统招 6 专业/37 方向、2027 推免 5 专业/27 方向）＋**校级培养工作规定**（学术学位硕士课程 ≥23 学分）。历史版 2 个时间点均为**页面层、非方案**（2017-05-11 美院首页、2017-05-09 研招网首页）。
- **⚠️ 浙江大学历史版的来源可信度**：2013 级、2014 级 130500 设计学硕士培养方案**来自第三方考研站 freekaoyan 转载**（页面标注 2014-02-18），**非官方原件、非 Wayback 快照**。按项目「引用必须到页码或快照日期」的纪律，这份**不能与官方原件同列**，引用时须显式标注来源性质。
- **共性障碍（两校共同）**：国内综合大学设计类的**课程层培养方案基本不在公开网页层**——清华在 Seafile 分享盘（403 挡死）、浙大在需登录的研究生教育管理信息系统；Wayback 对高校培养方案覆盖率极低（清华 cloud 域零存档、清华 ad 域 2 万条采样 0 命中「培养方案」、浙大 cst/grs/design 三域全 0 命中），**能拿到的历史版几乎只来自第三方考研站转载**。
- **archive.org 稳定性**：`web/` 快照端点本次普遍 HTTP 502，需重试 3 次才偶得；CDX 端点相对正常。后续批次应把 502 当常态。
- **通道复现差异（如实记录）**：子代理报告 `run_code` 内 Node 原生 fetch 可抓 `grs.zju.edu.cn`（含 https PDF 二进制）；我在主会话复核该站 Node fetch 与 web_fetch 均 failed。本条已写入 `03-培养方案/README.md` 附二。

## 6. 国外四校采集回报（2026-10-04，子代理回报）

- **MIT**：当前版到手——`catalog.mit.edu/subjects/mas/`（MAS 全量课程 72 条，研究生层 55）＋学位要求页（只给 4 terms in residence + 66 units，**不列必修课**）＋ Media Lab 学期课表 5 份。历史版 **1 个时间点**：快照 2021-12-16（MIT Catalog 2019-2020 归档页，研究生层 58 条）。障碍：2015-16 / 2017-18 / 2018-19 三学年 CDX 有 200 记录但**取回 0 字节**。
- **CMU**：当前版到手（MDes / MA Design Interactions 逐学期课程与 units；HCII MHCI curriculum）。历史版 **1 个时间点**：2019-06-19 / 06-20。障碍：无统一学分总量字段；2019 版 HCII 核心课页无逐门清单。
- **RCA**：当前版到手——10 个 programme 页 ＋ **7 份官方 programme specification PDF**（Unit Title / Term / Credit / Core-or-Elective 表，四校中质量最好）。历史版 **1 个时间点**：快照 2020-09-24（Design Products MA 页，原文 240 credits / 2 year programme）。障碍：programme finder 是 JS 应用（slug 从 sitemap.xml 取）；**IDE spec 为图像型 PDF**；2020-21 spec PDF 经 Wayback 取回 4,676 字节无效体。
- **UAL**：当前版到手（3 份 spec PDF）。历史版 **1 个时间点**：快照 2020-01-28（CSM 研究生课程指南 2019-20，35 页），但该件 **grep credits 命中 0、无模块表，不能做课程层对比**。
- **共性（四校共同）**：① 都没有国内式「培养方案 PDF + 招生专业目录」——MIT 只给在学学期数 + 66 units、CMU 逐学期列课与 units 但无总量字段、RCA/UAL 的模块层**只存在于 programme specification PDF**，网页正文只有方向/理念文字（**国内线「方向介绍 vs 课程层」的分层做法在这两校等价成立**）；② **四校都只拿到 1 个历史时间点，没有一所拿到 2 个**；卡点集中在「CDX 可见 200 记录但 `id_` 取回 0 字节」（MIT 三个学年、CMU 两页、RCA Service Design 2020）与「PDF 取回被截断为 1MB」（UAL 2021-22 spec），建议改用 `if_`/`im_` 变体或间隔重试。
- **⚠️ 一处与主会话复现不一致（如实记录）**：子代理报告 `arts.ac.uk` 全站对 Node fetch 与 curl 返回 **403 Cloudflare challenge（含 PDF 直链）**；但我在主会话用 Node fetch **成功下到 3 份 UAL programme specification PDF**（`ual-spec-2024-25-MA-Design-Ceramics-Furniture-Jewellery.pdf` 1,057,370 字节、2023-24 版 1,650,850 字节、MA-Regenerative-Design 2,590,706 字节，魔数均确认为 `%PDF`）。**结论：该站封锁是间歇性的**，取失败时应间隔重试，不要判「站点不可采」。
