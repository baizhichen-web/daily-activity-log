## 2. 核心障碍：清华官方培养方案汇编 PDF 有索引、无直链权限

### 2.1 检索定位到的官方培养方案汇编（**线索层，原件未取得**）

web_search 命中的 cloud.tsinghua.edu.cn 直链（检索索引里可见其**正文片段**，例如「A、基础理论课程(不少于3学分)」「美学 70800051 1学分 考试 秋」）：

| 文件名（解码后） | 直链形态 | 直接抓取结果 |
|---|---|---|
| 2023年研究生培养方案汇编-学术学位硕士生分册.pdf | https://cloud.tsinghua.edu.cn/seafhttp/files/7bd19b3d-a588-4a5a-865a-4fc22768cdf5/… | **HTTP 403**，正文 23 字节 = `Access token not found` |
| 2023级攻读专业学位研究生培养方案汇编（专业学位硕士生分册）.pdf | https://cloud.tsinghua.edu.cn/seafhttp/files/213fd0b6-7a27-4542-8920-b705c8b72494/… | 同上（未再逐条抓取） |
| 2023年研究生培养方案汇编-学术学位博士分册.pdf | https://cloud.tsinghua.edu.cn/seafhttp/files/421a037e-5717-466f-bb0d-a3c535d375cd/… | 同上 |
| 2020级培养方案-042101.pdf / 2022级培养方案.pdf / 2024级培养方案.pdf / 2023级培养方案.pdf / 2019级培养方案终版_0.pdf / 2016本科培养方案.pdf / 2017教学计划终版_0.pdf | cloud.tsinghua.edu.cn/seafhttp/files/… | 同上 |

**原因（事实层）**：cloud.tsinghua.edu.cn 是 Seafile 分享盘，`/seafhttp/files/<file-id>/<name>` 直链需要分享会话 token；无 token 时服务端一律返回 403。

### 2.2 已尝试的绕行与结果

| # | 尝试 | 结果 |
|---|---|---|
| 1 | 直接抓取 A1 节列出的 seafhttp 直链（Node fetch，跟随重定向） | **HTTP 403**，`Access token not found`（23 字节） |
| 2 | 抓取分享目录页 https://cloud.tsinghua.edu.cn/d/bc56c91e6b414a61bb6f/files/?p=%2F培养方案与教学计划 | **HTTP 200 / 7,106 字节**，正文为 Seafile 前端外壳 + `File does not exist` |
| 3 | 向分享目录页加子路径（培养方案与教学计划/研究生） | 未取到有效文件列表 |
| 4 | Wayback CDX 查 cloud.tsinghua.edu.cn（matchType=domain，limit=20000） | 多次返回空 / 失败；一次返回 **rows: 0** → **该域在 Wayback 无存档** |
| 5 | Wayback 快照端点取 cloud.tsinghua.edu.cn 的 PDF | 未执行（CDX 已判无存档） |

> 事实层说明：检索索引能看到这些 PDF 的正文片段，说明**索引方抓取时持有有效分享会话**；本会话没有该会话。
