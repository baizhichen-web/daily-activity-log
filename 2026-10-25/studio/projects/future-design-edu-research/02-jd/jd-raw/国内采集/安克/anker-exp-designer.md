# 体验设计师-深圳

正式｜校园招聘｜深圳

工作职责
你将参与：
1. 负责 App 及 WEB 端的界面视觉设计、功能迭代、改版等设计工作，提升用户满意度和品牌影响力；
2. 遵循并完善设计规范，保持产品视觉风格一致性；
3. 有良好的业务理解能力，能够清晰的理解产品业务目标；
4. 具备一定的产品和交互思维，能够参与到产品交互设计的日常需求讨论，配合项目上线时间，保证项目质量；
5. 熟悉和实时紧跟设计流行趋势，研究目标客户，持续性地优化和创新用户的整体体验。
任职资格
1. 2027届毕业生，硕士及以上学历，设计类相关专业优先。
2. 投递简历需包含相关项目作品集；
3. 对智能硬件、互联网领域的 UI 设计和交互设计有一定的理解和兴趣；
4. 具备良好的沟通能力，积极推进项目。
