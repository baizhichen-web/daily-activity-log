# AGENTS.md — 《艺术哲学》阅读项目

> 只收本项目特有规则；通用红线以工作区根 `AGENTS.md` 为准。

## 角色边界（沿袭读书空间定例）

- **AI 不代读、不代写。** 白纸先读、先划、先写；AI 只做校验、拆解、定位、批改。
- 笔记成文是白纸的活。AI 可以：定位原文、渲染图版、对照加德纳核实论断、对成稿提修改意见。
- **引用原文一律从 `source/艺术哲学-傅雷译.md` 复制**，不凭记忆复述；引用时标注章节名 + 行号（转换稿无页码）。

## 材料使用

- **一手批注在 Calibre**：书库 `F:\Calibre 书库`，sqlite3 只读打开 `metadata.db`，`annotations` 表取《艺术哲学》有批注的那本（库内有多个副本）。用户说「看我的笔记」时走这个通道。
- 主读本检索副本 = `source/艺术哲学-傅雷译.md`（markitdown 转换稿）。引用原文时 grep 这个文件，不要凭空引。
- 加德纳 = 纯扫描 PDF，走 `scripts/render-gardner.py` 按印刷页渲染 PNG 后看图；页号换算与章节地图在 `gardner-map.md`。
- 译名对照表在转换稿卷末（附录），人名译法以它为准。

## 过程记录

- 每场阅读：`notes/YYYY-MM-DD-第N场.md`（本场抄出的论点句 + 疑点）。
- 进度：`notes/progress.md` 追加一行（日期/场次/内容/卡点/疑点）。
- 概念入库按需，走知识库 Schema；本项目默认**只记进度与疑点，不自动建卡**——白纸点头再入。

## 边界

- 加德纳只做查证，不开通读任务；谁提议通读都要先问白纸。
- 换主读本/换译本先问；不自行替换材料。
