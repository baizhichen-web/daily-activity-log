## 这是什么

中国工业设计协会行业标准（工信部合作方向）的 PBL 项目，做**陶瓷技艺数字资产的描述、管理与设计应用规范**，服务工业设计与产业转化；与文旅局的传统文化遗产保护线相区别。

- **规范框架**：数据六字段（ISO 口径）——对象 / 来源 / 内容 / 条件 / 使用 / 质量
- **六项任务**：资源调查 / 行业调研 / 数据建设 / 标准比较 / 专题研究 / 案例验证
- **我的位置**：陈柏志（白纸），研一。**2026-10-22 已接到任务：广东陶瓷产业调研**（当前主任务）；其余分工待项目会议后定
- **团队**：项目组专家高鹏；研究成员藤依舒、李思洁、付卓然；案例搜集陈君倩、刘安、何天娇；国际比较朴林海、王云飞

## 当前产出（2026-10-20）

- 立项三件套：README + AGENTS + design.md v0.1
- 杨老师三件调研**底稿已出**：日韩公开数字库（6 库）/ 国内标准体系（15 条陶瓷标准）/ 产业政策（16 条，含财资〔2023〕141 号授权条文），见 notes
- 三条硬结论：①协会不能自行发行标，须工信部立项或团标先行；②六字段与国家数据资产会计披露口径同构；③日韩六库**零工艺参数**——这正是本标准的增量
- **广东调研**：整合报告 v0.2 已完成（`bAI/bAI/notes/2026-10-22-广东陶瓷产业调研报告-v0.2.md`，10 节＋目录）：产业地图 / 工艺链 / 设计—制造连接 / 数字化现况 / 设计企业对接平台五条桌面线合并为一份正式报告
- **广东调研核心结论**：①「总部设计＋异地制造＋打样对色＋版权登记」四段式回路，闸门在工艺会签与打样对色；②制造侧已系统化（AI 质检 99.8%、一砖一证），**交接侧空白**——22 项接口数据仅 2 项被系统管、8 项仍靠纸质/微信，空白集中在权利与留证；③标准增量＝设计—制造交接数据包（6 组 22 项）；政策抓手＝佛府办函〔2022〕183 号、潮州 2028 数字化全覆盖、2030 数控化率 85%/70%
