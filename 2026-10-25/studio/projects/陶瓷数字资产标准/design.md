## 0. 一页纸

**一句话**：把六字段从"六个问题"变成"可填、可查、可判"的字段规范，用钧瓷样本证明它能跑通，再把缺口交给团队变成标准条款。

**判断**：这个项目最缺的不是"再找几个数据库"，而是**把六字段落成可操作的数据规范**——这正是白纸 LoRA 数据清洗/标注/质检与钧瓷 30×8×5 数据流的可迁移处。资源调查是输入，标准比较是校准，案例验证是证据链；三者都服务于"字段规范能不能被真实数据填出来"。

**当前模式（2026-10-20 白纸决定）**：不预设分工，待项目会议后确定。会议前只做与分工无关的公共底座：

**会议后再定**：D1 分工 / D2 每周投入 / D3 对接方式；确认后再排 D1–D7 交付物与 30 天目标。

> **调研发现（2026-10-20，国内标准线）**：《行业标准管理办法》（市场监管总局令第 86 号，2024-06-01 施行）第三条规定，行业标准由**国务院有关行政主管部门**制定；中国工业设计协会是社团，**不能自行批准发布行业标准**。因此「协会行标」的真实路径只可能是两种：①协会起草、由工信部立项并发布（周期长、门槛高）；②协会先发团体标准（T/ 代号），实施成熟后再申请转化为行标。这个判断直接改变 Q2 与 D4，须尽快向杨老师确认。另：行标禁止写资质资格、许可认证、审批登记、评比达标、监管职责——本规范的「质量等级」只能是**技术性质量分级**，不能写成行政评级或登记资质。

### 1.4 政策依据（2026-10-20 已核实，可直接用于编制说明）

- **最硬一条**：财政部《关于加强数据资产管理的指导意见》（财资〔2023〕141 号）明确「支持企业、研究机构、高等学校、相关行业组织等参与数据资产标准制定」——中国工业设计协会牵头做本标准，属政策明确鼓励事项。
- **口径同构**：财政部《企业数据资源相关会计处理暂行规定》（财会〔2023〕11 号）要求披露「原始数据类型来源」「加工维护和安全保护情况」「相关权利失效和受限」，与六字段的来源/内容/条件/使用高度对应。→ 本标准不是自创分类，而是**国家数据资产口径在设计域的可操作化**。
- **产业定位**：工信部联消费〔2022〕68 号把陶瓷列入轻工业；工信部联产业〔2019〕218 号要求「设计基础数据积累」并鼓励制定团体标准。设计线与数据线在「设计数据」处交汇。
- **边界**：文旅非遗发〔2022〕72 号已提「传统工艺数字化保存标准」——本项目补的是设计应用/资产管理段，不重复保存、不越界。

### 1.5 日韩数字库调研的三个硬结论（2026-10-20 底稿）

- **分类是双轴，不是一棵树**：日本文化遺産オンライン 在同一门户并置「工芸品 > 陶磁」（器物/材质轴）与「工芸技術 > 陶芸」（技艺轴）；韩国用「项目（종목）+ 保有者（보유자）」给技艺单独立项。→ 标准必须允许「对象轴」与「技艺轴」独立编码、单品多值，不能强行合成一棵树。
- **六个库全部没有工艺参数字段**：字段止于法量/员数/材质/作品区分/受入年度/数据基准日；烧成温度、气氛、釉式、泥料配比、工序步骤只能藏在解説自由文本里。→ 这正是本项目要补的空白，也是标准相对日韩库的**核心增量**。
- **质量与使用靠「外部事实」表达**：质量=指定等级+评定日期、受入记录、数据基准日；使用=资产形态（文本/2D/3D/影像/工艺记录）× 授权方式（开放/PD/申请制/涉密）。→ 质量字段应做成可审计的三段式（权威性/完备性/时效性），使用字段按二维建模。

## 3. 数据六字段的操作化（本方案核心）

### 3.1 设计原则

1. **一对象一卡**：一个技艺/纹样/造型/操作方法一张记录；内容文件挂在卡下，不散落。
2. **字段 = 问题 + 证据**：每个子项不是自由文本，而是"回答什么问题、拿什么证明"。
3. **先最小可填集，再扩展**：首版只强制 15 项，跑通后再加；避免字段太多推不动。
4. **可机读但不绑定系统**：字段有稳定 ID 与枚举，但不规定用哪个数据库/软件。
5. **质量分级而非二元合格**：A 可复核 / B 可用待补 / C 存疑；允许"不完美但可追溯"的数据进入池子。
6. **区分事实与解释**：工艺参数、材料、来源是事实；风格判断、历史推断是解释，分开记。
7. **双轴正交 + 受控词表**：对象轴（材质/器类）与技艺轴（工序/技法）分别编码，单品可多值；建同义词映射（陶芸 vs 陶磁；陶器 vs stoneware；粉青沙器 vs 粉青瓷），解决跨馆用词不一。
8. **资产分层**：库 → 系列/批次 → 单品 → 视图（2D/3D/影像/工艺记录）。视图独立携带形态、精度、制作方、许可状态——同一器物的多模态资产不能挤在一条记录里。
9. **条件分两组**：物理条件（材质、尺寸、完残、员数）与工艺条件（泥料/釉料、成形/装饰/烧成、窑具、工序、工时良率）。工艺条件是本项目相对日韩库的增量。

### 3.2 字段字典讨论稿（v0.0，会议用；定稿升 v0.1）

| 子项 | 说明 | 要求 | 取值/格式 |
| --- | --- | --- | --- |
| F1 完整性 | 六字段必填项填充率 | 必填 | 百分比 |
| F2 准确性 | 与原始记录一致性；专家复核结论 | 必填 | 枚举 + 说明 |
| F3 可追溯性 | 来源链是否闭合（提供者→采集→文件→修改） | 必填 | 是/部分/否 |
| F4 可复核性 | 另一人能否按记录复现或验证 | 必填 | 是/部分/否 |
| F5 质量等级 | A 可复核 / B 可用待补 / C 存疑 | 必填 | 枚举 |
| F6 问题记录 | 缺什么、为什么缺、谁来补 | 选填 | 文本 |
| F7 复核人/日期 | A 级必须有 | 条件必填 | 文本 + 日期 |

### 3.3 最小可填集（首版只强制 15 项）

A1 对象名称、A2 对象类型、A4 工序环节、A6 粒度；B1 提供者、B2 采集者、B3 采集时间、B6 权利状态；C1 内容类型、C2 文件清单；D1 材料、D3 关键工艺参数；E1 设计场景、E2 使用范围；F5 质量等级。

其余选填；试填 3 个对象后，按"填不出来/填了没用"两类反馈调整必填集。

### 3.4 质量规则（把 LoRA 数据清洗经验翻译过来）

- **三段式（可审计）**：权威性（指定/评定等级 + 评定日期，参照国宝/重要文化財/国家无形遗产）、完备性（是否含法量、员数、解説、图像、工艺记录，做成 checklist）、时效性（数据基准日 + 更新声明）。三段都能判定、能审计，避免「质量」沦为形容词。
- **三查**：
  - 源查：能否回到提供者/原始记录？
  - 一致查：同一对象的多来源是否矛盾（文献 vs 访谈 vs 设备记录）？
  - 复现查：设计师/技师按记录能否复现或至少验证关键参数？
- **抽检**：每批 10% 双人复核；A 级 100% 复核。
- **先定"坏样本"再清洗**：训练 LoRA 的教训是"坏样本定义不清，标注一定漂移"。对应到本项目：先列"什么算不合格数据"（无来源、无授权、参数无单位、图片无对应对象），再谈补全。
- **分级不追求全 A**：B 级数据只要标明缺什么，就可以进池；C 级只做线索，不进标准依据。
- **措辞红线**：质量等级是**技术性描述**（数据完整度、可复核性），不是对机构/个人的资质评级、许可或认证；标准文本中不得出现「登记/评级/资质」一类行政性表述（依据：《行业标准管理办法》第六条）。
