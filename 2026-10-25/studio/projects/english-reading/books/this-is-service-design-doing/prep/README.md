# prep/ — 备课材料（AI 侧答案册）

> **这是 AI 的备课夹，不是白纸的学习材料。** 陪读会话按 `../AGENTS.md`（书级）与 `../../AGENTS.md`（书架级）规则进行，本目录只服务一件事：**白纸发段落之前，AI 已经把功课做好**。

## 使用规则（陪读会话必读）

1. **后置原则**：本目录的逐句分析是批改对照用的参考答案。白纸没划主干、没自己先读之前，**不给看对应分析**。
2. **翻译最后给**：`全文忠实翻译` 只在白纸读完整节之后按需给，永远不放前面。
3. **生词候选 ≠ 生词表**：`生词候选` 未与读者校准，**禁止写入 `../vocabulary.md`**。
4. **预出题到点才出**：先只给题目，白纸可「跳过」。
5. **冲突时以白纸的划法为准**：参考分析只是 AI 一家之言，批改是对照，不是审判；结构有歧义的句子不强判。

## 文件命名与结构

沿用 v3 深析规格（见在读的 Wakkary 一书 `prep/README.md`）：

- **章文件夹**：`ch<两位章号>/`，内含 `README.md`（节级索引）+ `P<两位段号>.md`（一段一深析）。
- **每句固定结构**：朗读分组 → 线性串讲+预期追踪 → 主干（方法命名+误读演示）→ 结构树（折叠/展开）→ 全词细讲（词族/全书词频/后文摘例）→ 语法点 → 指代省略熟词僻义 → 翻译（直译对照+忠实译文）→ 这句在干什么。
- 段文件头：段落论证图；段文件尾：复习锚点（自测题 + `<details>` 折叠答案区）。
