## 翻页书全局规则（MVP 拍板：Trestle 式，Product.md §8）
- 一屏一页：`scroll-snap` 横向整屏翻页；**翻页输入=滚轮**（ deltaY 映射横向；页内可纵滚内容优先吃滚轮，到底才翻页——白纸拍板 2026-09-01，禁 ← → 键）；禁全局纵向长滚
- 页码指示器：顶部中央常驻 `第 N 页 · 页名 / 总页数`（mono，MVP 拍板件；元件形态待白纸另找）
- 翻页动效：入场 .rv 错峰揭示（0/.12/.24 级联）；页内交互可打断；reduced-motion 全淡入淡出
- 四角活数据（ruixen 式"实况即人格"）：左上时间 / 左下屏宽 / 右下操作提示
- 全局中性：导航/指示器/四角永不上色（项目色只进项目页内容区）
- 禁手写日期；零假数据；对外数字才入页

## 页面模板（书=页序列，按 user stories 分页）

### T2.1 开场（loader-motto，全站唯一）
座右铭逐字渐显（如切如磋如琢如磨）→ 点按/自动进入；短+可跳过（HIG Launching + 白纸纪律）。不进页码序列。

### T2.2 首页 v1＝全幅海报墙（✅✅ 白纸裁决 2026-09-01 晚：**继续推进 v1**＝首页定版；对标 Scott/R-27 实测复刻；欠动效）
> 白纸："你的现在网站的排版完全是混乱的……Templates.md 中我要求你完全按照这个页面来设计"——撤自我此前的两列网格/四角活数据等发明，回到 Scott 实测结构。

**实测数值（scott-fryxell.github.io，2026-09-01 DOM 核验）**：
- **头栏**：`position: sticky/fixed`，全幅；左＝姓名 + 一行大写小标签（Scott: "HUMANIST SOFTWARE DEVELOPER"），右＝文字链（Resume / Thoughts 式，我们＝Resume / Contact）；**无页码指示器压在头上**（我们的指示器改到头部下方，让位 56px）
- **海报墙**：`main` **无 max-width=全幅 100vw**；单列纵向堆叠；**每张海报高 = 72vh**（实测 485px / 视口 674）；**海报间距仅 1px**（紧贴，靠发丝线分隔，不是网格 gap）
- **标题压图**：文字**叠在海报图上**、左下对齐；标题 Scott=31px/字重300 细体——我们用 tokens 的 fs-display 起步、weight-normal（400 为最轻档，体系内无 300）；标题下一行小字日期（mono）；**右下角一个 `+` 号**（展开暗示）
- **图**：海报满幅=项目最有代表性一张（占位槽，白纸 Figma 导出填入，零假数据）

**交互（G-21 展开，与 Scott 同源）**：点海报 → 该海报高度自适应、正文长图文在图下方铺开（`+`→`×`）；**墙内纵向滚动优先**，滚到底才横向翻页（白纸拍板：滚轮翻页、禁 ← →）。

**分类**：一屏即全部，不分"项目/博文"两栏网格（Scott 单列同构）；如后续要区分，用墙上的 mono 小标签分节，不做并排双列。

**装配源**：`web/src/demo/FlipbookDemo.tsx`（v4 已按上述实测复刻，海报 72vh/缝 1px/全幅/标题压图/头 fixed 全部真机核验通过）
