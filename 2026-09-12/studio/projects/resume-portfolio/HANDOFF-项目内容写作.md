# HANDOFF · 毕业设计项目内容组织（交给新会话）

> 目的：让**新会话**接手"把毕业设计素材组织成一篇项目介绍，并录入网站内容系统"这件事。
> 本档自包含；新会话只需读这一份 + 下面点名的两份文档即可开工。
> 关联项目：`studio/projects/resume-portfolio/`

## 0. 一句话任务

把白纸提供的毕业设计素材（文字、图片、视频）**组织成一篇项目介绍**，按既定的内容模型落成结构化内容，成为网站的第一个项目条目。

（为 3–6 岁儿童设计的自然探索与物理创作智能终端：以摄影为主、语音为辅采集创作意图，实时转化为可折叠纸模图纸并即时打印）

## 2. 已经就位的东西（不要重复劳动）

- **内容系统**：Decap 后台已装好，项目集合 schema 已定义（11 个字段 + 8 种正文块）
  - 后台入口：`http://localhost:5175/admin/index.html`
  - 配置：`web/public/admin/config.yml`
  - 启动命令：`npm run dev`（站点）+ `npm run cms`（内容写入代理），均在 `web/` 目录下
- **条目骨架已建**：`web/content/projects/zhezhi-printer.yml`
  （标题/时期/角色/状态/摘要已填，正文含一个草稿旁注 + 两段原述 + 一个待填的四问结构）
- **规则文档（必读）**：
  - `design/内容架构-v0.1.md` —— 内容模型、块类型表、媒体红线、组件清单（**本任务的格式依据**）
  - `studio/design/Product.md` §4/§7 —— 内容边界（零假数据、对外数字才入页、性质条款）
  - `studio/design/Design.md` A2/A4 —— 黑白双层色制、编辑部四件（决定文字的强调方式）

## 3. 写作要求（硬约束）

1. **叙事口径 = 四问结构**：问题 → 决策 → 取舍 → 结果（PRD §1 G2：展示判断力而非成品堆砌）
2. **零假数据**：数字必须对外可验证（奖项、专利、测试数据、用户量级）；没有就留占位并标注"待补"
3. **口吻**：第一人称、克制、具体；**禁**宣言空话、王婆卖瓜、"证据链/可生长"这类自我描述词
4. **结构**：小节用 H2（自动进左侧目录）；每张图必须有图注；图组按过程顺序编号
5. **不脱敏**：真实数据可用；未公开的技术细节（如企业未发布产品）不写
6. **不得编造**：素材里没有的事实一律不写；需要补充时列成问题清单回问白纸

## 4. 输出与落库（二选一，建议②）

**① 白纸自己在后台排版**：新会话只产出"文案 + 图片清单"，白纸照着重录。
**② AI 直接写结构化内容**（更快）：
- 正文写成 YAML 块数组，落到 `web/content/projects/zhezhi-printer.yml` 的 `body` 字段
- 块类型与字段名严格照 `design/内容架构-v0.1.md` §2.3（`paragraph` / `heading` / `figure` / `gallery` / `video` / `quote` / `process` / `note`）
- 图片放 `web/public/media/zhezhi-printer/`，命名 `01-语义.webp`，正文里引用 `/media/zhezhi-printer/01-语义.webp`
- 写完后白纸在后台打开该条目校对（后台读的就是同一份文件）

## 5. 媒体红线

- 单图源文件 ≤ 2MB；构建期压缩交给站点管线
- 短视频（<15s、<20MB）可自托管：`/media/zhezhi-printer/xxx.mp4` + 封面图
- **长视频不要提交进仓库**（git 历史无法瘦身）：贴 B 站/YouTube 外链，页面只放封面 + 播放入口
- 论文全文 PDF 不上站，可作附件链接或只摘关键页

## 6. 开工前先问白纸（一次一个，带默认建议）

1. 这篇介绍的读者与用途？（建议：招聘方/学院，偏"判断力 + 完成度"）
2. 论文里的哪些内容**不能**公开？（企业合作、未发布技术、导师要求）
3. 图片素材的授权与出处标注要求？
4. 视频是本地文件还是平台链接？

## 8. 验收标准

- 文案：四问结构完整、每张图有图注、无编造事实、无空话
- 结构：H2 小节 ≥3（左侧目录才成立）、至少 3 张图 + 1 个视频位
- 落库：后台能打开该条目并看到全部块；`npm run build` 通过
- 视觉：与简历页同一体系（衬线文档流、发丝线、tokens 取色）
