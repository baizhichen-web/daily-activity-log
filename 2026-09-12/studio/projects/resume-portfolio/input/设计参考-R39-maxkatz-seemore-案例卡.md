# 设计参考 R-39 · maxkatz.me ——「See more」渐进披露

> 来源：https://maxkatz.me/ （Max Katz，全栈工程师个人站）
> 白纸指定（2026-09-12）："我希望你学一下这个，类似这样，点击 see more 可以展开"
> 用途：简历页长内容的阅读减负 → 已落地（见 §4 落点）

## 一、实测（2026-09-12，真浏览器 DOM 核验）

| 项 | 值 |
|---|---|
| 字体 | Geist（含 Geist Fallback） |
| 正文 | 16px / 行高 24px（1.5） |
| 版心 | 主栏 700px，内边距 32px（单栏居中） |
| 页面总高 | 1526px（展开一段后 1877px） |
| 节标题 | 16px / 字重 500（与正文同号，靠字重与间距分节） |
| 切换控件 | `<button>`（非 `<details>`），文案 `See more` ↔ `See less`，12.8px 灰字，圆角胶囊（"squircle"） |
| 位置 | **节标题行右端**（`Experience ⋯ See less ✕`），不是列表下方的独立按钮 |
| 效果量级 | Experience 段：收起 132px → 展开 483px（约 3.7 倍）；整页 +351px |

## 二、机制

- 收起态 = **紧凑时间线**：一行一条（公司名 + 起止时间右对齐），无描述
- 展开态 = 完整条目（公司/职位/时期·地点 + 要点条目）
- 纯 React 状态切换；无 `<details>`、无 URL 变化、无动画证据（瞬时展开）
- 可同时展开多段（各段独立状态）

## 三、我们采了什么

1. **切换控件放节标题行右端**（`margin-left:auto`），与节标题同一基线 —— 直接搬
2. **紧凑态 = 前 N 条 + 展开看余下**（对方是"摘要态 vs 明细态"，我们内容同构，用前 N 条即可）
3. **文案双语**：中文「展开 ↓ / 收起 ↑」、英文 "See more ↓ / See less ↑"（mono 声部，A4 编辑器语言）
4. **动画**：对方无动画；我们用 JS 测高 + `max-height` 过渡（320ms，ease-out），reduced-motion 瞬时——守"旧内核降级安全"纪律

## 四、我们没采

- Geist 字体（我方 A3 拍板：Inter + 思源黑 + JetBrains Mono）
- 节标题与正文同号（我方节标题 18px 衬线 + `§ N` 编号 + 发丝线，是已拍板体系）
- 圆角胶囊按钮（我方切换控件走 mono 文字 + 下划线 hover，更贴黑白双层制）
- 图标点缀/手写体箭头等个性化元素
