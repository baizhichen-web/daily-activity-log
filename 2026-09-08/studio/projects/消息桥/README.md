## 这是什么

学校消息（微信群为主：班级群、学院通知等）的处理流水线：

```
白纸上人工投递                     AI 四动作                        去处
微信多选合并转发 ──粘贴──▶ 飞书「自动化通知」群 ──▶ ① 归档消息卡 ──▶ 消息中台区（真身）
（⚠️ 紧急当场单发）        chat_id oc_748101c9fa6326c2df919bf2b98eb5b1   ② 排飞书日程（带原生提醒）
                                   ③ 挂看板行动项 ──▶ 工作空间看板
                                   ④ 知识库指针卡 ──▶ bAI raw（摘要+路径，不复制全文）
                                   ⑤ 回执 ──▶ 次日 9:00 晨间提醒「昨日归档 N 条」
```

- **SOP v1 = 纯人肉投递 + AI 处理**（零风险，立即可跑）
- **升级路径**：跟踪微信官方 `Tencent/openclaw-weixin`（ClawBot）——目前仅支持私信，Issue #198（转发给 Bot）未解决；官方一旦支持群消息/转发，升级为**微信内直投、零切换**

## 红线

1. **不用任何微信协议/hook 方案**（wxauto 等已降级为兜底档，见 design §5）——学校群消息是命脉，封号不可承受
2. **不双写**：真身在消息中区，知识库只放指针，看板只放行动项
3. 装机（OpenClaw 等）、常驻自动化、微信侧脚本，一律**先报批**
