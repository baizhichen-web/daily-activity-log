# AGENTS.md — AI 求职工坊（job-search）

任何 Agent 进入本目录先读完此文件再动手。

## 项目定位

双面项目：
- **网站侧**：个人网站（resume-portfolio）的 AI Native 求职功能——「让大家来找我」意图组件 + JD 动态简历
- **工具链侧**：白纸 2026 秋招/实习的五模块工作流（方向图谱 / 主简历 / JD 匹配 / 追踪表 / 定制包）

上游依赖：个人网站项目（`studio/projects/resume-portfolio/`，简历 yml 是真源）。

## 阶段红线（当前：PRD 评审中）

1. **PRD 拍板前零实现代码**——不建脚本、不改网站源码。调研、方案对比、素材整理可以做。
2. 立项文档在 `PRD-v0.1.md`；白纸逐条批注后升级 v0.2 → v1.0 才开工。
3. 每个模块开工时在本目录建 `modules/<模块名>/`，各自带 README（输入/输出/用法）。

## 数据红线

- **简历真源唯一**：`resume-portfolio/web/content/resume.{zh,en}.yml`。所有衍生物（关键词图谱、定制简历、PDF）从真源生成；禁止手工复制一份「简历副本」另头维护——要改就去改真源。
- **访客 JD 零上传**：网站端 JD 处理默认纯前端（方案 A）；若未来选方案 B（LLM 后端），必须先向白纸说明数据流向并重新过隐私关。
- **第三方招聘信息**：JD 全文是从招聘平台抓的内容，仅用于白纸本人的匹配分析，不整段公开挂网（版权与平台条款）；可以挂的是「关键词、要求摘要与匹配结论」。
- **投递追踪表**含公司/进度等个人信息：默认存飞书多维表格（云端优先、白纸可随手编辑），不进 git 仓库；表结构定义可以入库。
