## 2. 产品定义

**白纸上个人网站**：设计出身的硬件产品经理（北师大未来设计学院 2026 级）的公开站点——一本可翻阅的作品与简历之书。

## 3. 座右铭（定位主句）

- **中文主铭**：如切如磋，如琢如磨 ——《诗经·卫风·淇奥》（孔子于《论语·学而》引之，治学亦如治器）
- **英文配铭**："I saw the angel in the marble, and carved until I set him free." — Michelangelo（轶语；正史文献为其十四行诗）
- 用法：中英不做直译对仗，做**典故对仗**——一个管过程（反复修治），一个管视野（先看见再雕出）
- 出现位置：加载屏逐字渐显 + Hero 主位

## 4. 站的性质（内部准则，页面零出现）

一句话：**可生长的公开证据链，非简历 PDF 搬家；项目本身即证据。**

三条细则：
- a. **允许并标注进行时**：在建/下一步也是证据，但必须带状态标签（latest / ongoing / archived）；未完成的事标注状态，不藏
- b. **起源故事是证据的一部分**：每个项目条目鼓励一句起源叙事；叙事不替代证据，是证据的入口
- c. **宣言禁令的边界**：禁无事实支撑的形容词句；许有事实锚点的立场句。座右铭为典故引用，不在禁令内

**铁律：性质入则不入文**——「证据链」「可生长」等自我描述词不出现在页面文案里（访客从结构与内容自行得出结论）。

## 5. 个人特色（第一印象简历）

1. **学生背景**：北京师范大学（未来设计学院 2026 级）
2. **职业身份**：设计师
3. **理性视角**：做设计有理性视角——用数据说话、用程序说话
4. **技术全面**：掌握较多技术内容，相较感性派设计师更「全栈」

**60 秒测试**（内部验收标准，页面零出现；Evaluator 层执行）：
- 考核一：陌生访客 60 秒后能概括出四点中**至少两点**
- 考核二：能转述**至少一个对外数字**（下载量/使用量/奖项名次——仅对外可验证者）

## 6. 访客与读法

- 三类访客（recruiter / 学院 / 同行），**一本书一种读法**，无分流门、无入口分流
- 页序即读法：Hero 起手即含联系入口 → 项目页居中 → 简历页 → 尾页联系收口
- 学院/同行深读 = 翻完全书；recruiter 快读 = 起手页+项目页扫读即得关键信息

## 7. 内容边界（七条）

1. **简历 PDF 以链接形式上站**（双语版）；作品集 PDF 整本不上站，拆条目进项目页
2. **联系方式**：邮箱（点击复制+toast）+ 手机号（tel: 链接）
3. **零假数据**：占位槽空时显示占位样式不编造；评语等无素材区块整体隐藏
4. **图片白纸放**：槽位与样式由 Agent 负责，内容由白纸填；素材源 **Figma 矢量导出优先**（作品集原始文件全在 Figma），PDF 拆页兜底
5. **不脱敏**：企业名/合作方/人物名如实保留（19 站调研实证：实名雇主为通行做法）
6. **日期全站禁手写**：仅允许构建时自动生成的 Updated 戳（可选）
7. **数字对外可验证才入页**：下载量/使用量/奖项/问卷量可；工作空间内部指标（测试数、调研数）不入

## 8. MVP（v1 上线版）= Trestle 式翻页书

**整体骨架**：整站 = 一本一屏一页的书，滚轮 scroll-snap 翻页；顶部中央固定**页面指示器**（页码/内容名 + 进度点，翻页更新，可点击跳页）。

1. **加载屏**：暖纸底，座右铭「如切如磋，如琢如磨」**逐字灰→黑渐显**（Trestle per-letter fade 实证，2026-08-27 视频逐帧拆解；英文配铭可作第二行小字后置）；打完整层淡出进书
2. **页 01 · Hero**：座右铭 + 定位副行 + 状态行（正在做什么）+ 联系入口（邮箱/手机）
3. **页 02-0N · 项目页**：一项目一页，大图少字（Behance/普象式）；**占位槽制**——页数与槽位先留好（6-9 页），图片白纸从 Figma 导出后填；每页支持**「展开看细节」**（G-21：+ 旋转 ×、大图收缩让位、正文浮现，原生 details 语法，R-27 平移）
4. **简历页**：结构化**简化版**（只放重要信息：教育/经历/技能/获奖）+ **双语简历 PDF 链接占位**
5. **尾页 · 联系**：邮箱（复制+toast）+ 手机（tel:）+ 社交链接 +「下载简历 PDF →」

**MVP 明确不做**（进 backlog）：幽灵字轮播、数据带、热区图、评语区、可玩展区、Updated 戳。

**实现策略（2026-08-30 白纸授权，按 AI 观察落定）**：
- 动效与组件实现以 **I-02~I-05 开源库为参考源**（React Bits / Motion Primitives / fancy / shadcn-studio 核心，全 MIT）：需要哪个效果**逐件抄写其源码**，改造挂到自建 spring/令牌体系上——**不引入 Framer Motion / Tailwind 整库依赖**（用量配不上重量；motion/spring.ts + ClipText 基建已验收，G-20 同纪律）
- 对应关系：加载屏逐字渐显 ← React Bits SplitText/BlurText 参考 + R-31 theme.js 预置底色手法；翻页 = CSS scroll-snap；展开看细节 = 原生 details（G-21）；若自建吃力再议引入 Framer Motion（须单独拍板）
