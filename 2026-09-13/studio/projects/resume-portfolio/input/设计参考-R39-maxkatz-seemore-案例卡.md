## 二、机制

- 收起态 = **紧凑时间线**：一行一条（公司名 + 起止时间右对齐），无描述
- 展开态 = 完整条目（公司/职位/时期·地点 + 要点条目）
- 纯 React 状态切换；无 `<details>`、无 URL 变化、无动画证据（瞬时展开）
- 可同时展开多段（各段独立状态）

## 三、我们采了什么

1. **切换控件放节标题行右端**（`margin-left:auto`），与节标题同一基线 —— 直接搬
2. **紧凑态 = 前 N 条 + 展开看余下**（对方是"摘要态 vs 明细态"，我们内容同构，用前 N 条即可）
3. **文案双语**：中文「展开 ↓ / 收起 ↑」、英文 "See more ↓ / See less ↑"（mono 声部，A4 编辑器语言）
4. **动画**：对方无动画；我们用 JS 测高 + `max-height` 过渡（320ms，ease-out），reduced-motion 瞬时——守"旧内核降级安全"纪律

## 四、我们没采

- Geist 字体（我方 A3 拍板：Inter + 思源黑 + JetBrains Mono）
- 节标题与正文同号（我方节标题 18px 衬线 + `§ N` 编号 + 发丝线，是已拍板体系）
- 圆角胶囊按钮（我方切换控件走 mono 文字 + 下划线 hover，更贴黑白双层制）
- 图标点缀/手写体箭头等个性化元素

## 五、落点（2026-09-12，含白纸纠正后的修订）

**关键纠正（白纸 09-12）**：一轮实现把收起态做成"只显示前 N 条"，**错**。参考站收起态是**另一种表示**——
横向时间轴一屏概览**全部**条目（圆点+连线+图标+名称+日期），展开才切明细列表。
即：**概览 ≠ 截断**；收起态必须能一眼看全，而明细态给深度。

| 节 | 收起态（概览表示，均含全部条目） | 展开态（明细表示） |
|---|---|---|
| § 2 专业之外 | 首段 + 4 个词条 chips（足球/阅读与写作/书法/技术社区） | 每条带说明文字 |
| § 3 实习经历 | 2 行紧凑行（公司 — 职位 ····· 时期） | 完整条目 + 要点条目 |
| § 4 其他项目经历 | 5 行紧凑行（标题 — 注解 ····· 时期） | 完整条目 + 描述段落 |
| § 5 获奖 | 两栏网格（奖项名 + 年份），8 + 9 全列 | 单栏编号行 + 详情 |
| § 6 部分课程成绩 | 三栏密排（课程名 + 分数），17 门全列 | 按四组分组 + 组标题 |
| § 7 自我评价 | 首段 | 引文与全文 |

实测：收起 3332px（概览全部内容）→ 全展开 5808px；收起/展开切换时概览元素隐藏（`.fb-crow/.fb-chip/.fb-agitem/.fb-cgitem` 计数 7/4/17/17 → 0/0/0/0）；各节状态独立；`aria-expanded` 正确。
组件：`CompactRow` / `AwardCell` / `.fb-chips` / `.fb-coursegrid`（概览）＋ `Reveal` / `SectionToggle`（明细与切换钮），均在 `web/src/demo/FlipbookDemo.tsx` 与 `flipbook.css`。
