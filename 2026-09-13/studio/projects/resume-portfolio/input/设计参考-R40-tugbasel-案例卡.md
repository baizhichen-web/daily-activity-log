## 二、版式（两栏：左身份卡 + 右正文）

**左栏（sticky 身份卡）**：头像 → **姓名（粗）** → 角色（灰）→ 社交短标行 → 本地时间 → 一句话自述 → 导航（Works / Shots / About）

**右栏（滚动正文）**：大图头像照（圆角矩形，约 145×150）→ `About` 小标 → `Hi, I'm Tuğba ✌🏻` 标题（约 28–30px）→ 四段正文 → **四张照片横排**（圆角、轻微旋转、错落）→ 结尾一段

## 三、可借（本次已用于 R-40 的身份块重排）

1. **身份卡信息层级**：头像 → 姓名 → 角色 → 社交 → 自述 —— 一眼完成"这是谁、做什么、怎么联系"
2. **社交用短标**：`X / IN / DR / MA` 两字母缩写，比写全名干净（我们用图标行代替，见 R-39 的图标行）
3. **本地时间**（"实况即人格"）：与 Templates.md 四角活数据、ruixen 的 pulse-dot 同族——**可作我们的候选件**（本页未实现）
4. **照片条**：四张圆角照片轻微旋转错落，比规整网格更有"人味"——可作项目页图组的备选排法

## 四、不采 / 注意

- **字号过小**：正文 14px、站名 14px——低于我们 Craft 红线的可读性底线（HIG 正文最小档），我们保持 16px 正文
- **原站有错字**（"desginer"）：只借版式，不借文案
- 左栏 sticky + 右栏滚动的两栏结构：与我们"单栏文档流"的拍板冲突，**仅借身份卡内部层级**，不改成两栏
