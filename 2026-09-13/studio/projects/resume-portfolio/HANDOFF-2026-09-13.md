## 3. 打磨方法论（本会话沉淀，防再犯）

- **动效评审尺**：Emil `review-animations` 十条标准（装机在 ~/.agents/skills/）。本轮实测修正：展开 320→240ms、缓动 cubic-bezier(0.22,1,0.36,1)、概览↔明细补 fb-swap-in 入场、chevron 旋转。**有意偏离并记录**：Reveal 仍用 max-height（旧内核兼容优先）。
- **三证法**：字体命中/样式生效不能靠 `document.fonts.check` 或目测单图——用 **computed stack + 同区间像素差 + 目检**。
- **DOM 计数照妖镜**：重复 key 致 DOM 累加（17→34→51）这类"看着没问题"的 bug，靠节点计数/溢出扫描/触控尺寸暴露。生产构建无 React 警告。
- **时序采样**："写了动画"≠"动画播了"（加载屏退场 bug：条件写法导致卸载先于置位）——用 iframe 时序采样验证。
- **React Bits 取舍**：AnimatedList 依赖 motion/react（Product.md §8 禁引整库）→ 只借手法不引库。
- **参考站教训（二犯）**：白纸给参考站=复刻目标；体系冲突处**先问**（AskUserQuestion），不自行过滤。
